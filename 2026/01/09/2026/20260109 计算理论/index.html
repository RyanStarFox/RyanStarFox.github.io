1 Finite Automata and Regular Languages

Machine Semantics Syntax
DFA Regular Regular Grammer
NFA Regular Regular Grammer

1.1 Deterministic Finite Automata (DFA)

定义：五元组$(Q,\Sigma,\delta,q_0,F)$

  1. (Q) is a finite set called the states
  2. (\Sigma) is a finite set called the alphabet
  3. (\delta: Q \times \Sigma \to Q) is the transition function
  4. (q_0 \in Q) is the start state
  5. (F \subseteq Q) is the set of accept states

注意其中第三条，(Q)中任意一个元素，都要和$\Sigma$中任意一个元素有这样一个函数

1.2 Nondeterministic Finite Automata (NFA)

也是五元组$(Q,\Sigma,\delta,q_0,F)$，第三条不太一样

  1. (Q) is a finite set called the states,
  2. (\Sigma) is a finite set called the alphabet,
  3. (\delta: Q \times \Sigma_\epsilon \to \mathcal{P}(Q)) is the transition function, where (\Sigma_\epsilon = \Sigma \cup {\epsilon}),
  4. (q_0 \in Q) is the start state,
  5. (F \subseteq Q) is the set of accept states.

1.3 DFA & NFA

任意一个NFA都存在和它等价的DFA

使用NFA节点的集合作为DFA的节点即可

$(Q,\Sigma,\delta,q_0,F)\to(P(Q),\Sigma,\delta’,E(q_0),F’)$

  1. $Q\to P(Q)$取幂集

  2. $\delta\to\delta’:\delta’(R,a)=\bigcup{E(q)|q\in Q\wedge(\exists r\in R)(q\in \delta(r,a))}$

  3. $q_0\to E(q_0)$

  4. $F’={R\in Q’|R\cap F\ne\varnothing}$

1.4 Regular

A language is called regular if some finite automata recognizes it.

具有封闭性的运算：

  • Union：$A\cup B={x|x\in A\vee x\in B}$
  • Concatenation: $A\circ B={xy|x\in A\wedge y\in B}$
  • Kleene Star: $A^*={x_1x_2\cdots x_k|k\geq 0 \wedge x_i\in A}$
  • Complement: $\bar A={x|x\notin A}$

注意：

$(01)^\epsilon=(01)^$

$(01)^*\varnothing=\varnothing$

** $\varnothing^\ast={\epsilon}$**

1.5 Pumping Lemma

证明不是正则语言：pumping lemma
对每个无限正规语言 $L$，存在一个常数 $p \ge 1$（pumping length），使得
对任意字符串 $s \in L$ 且 $|s| \ge p$，可以写成：$s = xyz$，满足：

  1. $|xy| \le p $（前 p 个字符内包含 x 和 y）
  2. $|y| \ge 1$ （y 至少非空）
  3. 对所有 $i \ge 0$，$xy^i z \in L$

证明是正则语言：构造一个DFA或者NFA

满足pumping lemma是正则语言的必要不充分条件

pumping lemma的证明使用抽屉原理

它只是必要条件，但不充分。满足Pumping Lemma但不是正则语言的反例：

  1. $L={a^nb^nc^n}\cup{a^ib^jc^k|i,j,k不全相等}$
  2. $L={a^ib^jc^j|i\geq1,j\geq0}\cup{b^ic^j|i,j\geq0}$
  3. $L={a^ib^jc^k|i=0\or j=k}$

1.6 三个问题

Q1: Acceptance: $w\in L(A)$？

可以解决，走一遍就可以了

Q2: Emptiness: $L(A)=\varnothing$?

可以解决，看看所有可能的路径能不能走通就行

Q3: Equality: $L(A)=L(B)$?

可以解决

$\Leftrightarrow L(A)\oplus L(B)=\varnothing$

2 Context Free Languages

2.1 Definition

定义：四元组$(V,\Sigma,R,S)$

  1. $V$ is a finite set called the variables,
  2. $\Sigma$ is a finite set, disjoint from V, called the terminals,
  3. $R$ is a finite set of rules, with each rule being a variable and a string of variables and terminals,
  4. $S\in V$ is the start variable.

2.2模糊性

  1. 规定优先级：Leftmost Derivation，先展开左边的

但是依旧不能解决模糊性，之后的称为真正的模糊性

事实上：

  1. 不存在去除一个CFG的Ambiguity的算法
  2. 不存在一个判断任何CFG是否Ambiguous的算法

2.3 Chomsy范式

定义：

  1. 只允许$A\to BC$或者$A\to a$，其中$a$是终结符，$B，C$是非起始变量的变量
  2. 允许$S\to\epsilon$，其中$S$为起始符

定理：

  1. 所有CFG都可以用Chomsy范式解释
  2. $\forall G\in\text{CFG},w\in L(G),w\ne\epsilon$ can be derived from the start state in exactly $2|w|-1$ steps

2.4 Pushdown Automata (PDA)

CFG对应的机器是 Pushdown automata

定义是六元组$(Q,\Sigma,\Gamma,\delta,q_0,F)$

  1. $Q$ is a finite set of states,
  2. $\Sigma$ is a finite set of input alphabet,
  3. $\Gamma$ is a finite set of stack alphabet,
  4. $\delta$: $Q×\Sigma_ϵ ×\Gamma_ϵ →\mathcal P(Q×\Gamma_ϵ)$ is the transition function,
  5. $q_0 ∈Q$ is the start state,
  6. $F ⊆Q$ is the set of accept states.

其实就是压栈弹栈的过程

需要有一个起始符，先压入栈，表示栈底

2.5 CFG等价于PDA

  • 已知CFG，构造PDA：画出状态转移图即可

  • 已知PDA，构造CFG：

    • 简化PDA

      • 只有一个接受状态
      • 接受状态后栈空
      • 每次转换仅仅压栈一次或者弹栈一次

    • 分类构造CFG

      Give $(Q, Σ, Γ, δ, q_0, q_{accept})$. We construct CFL $G$.
      with variables set ${A_{pq} | p, q ∈ Q}$, start variable $A_{q_0,q_{accept}}$. The rules are as followings:

      1. For each $p, q, r, s ∈ Q$, $u ∈ \Gamma$, and $a, b ∈ \Sigma_ε$, if
        $(r, u) ∈ δ(p, a, ε)$ and $(q, ε) ∈ δ(s, b, u)$, put the rule
        $A_{pq} → a A_{rs} b$ in $G$.
      2. For each $p, q, r ∈ Q$, put the rule $A_{pq} → A_{pr} A_{rq}$ in $G$.
      3. Finally, for each $p ∈ Q$, put the rule $A_{pp} → ε$ in $G$

2.6 性质

  1. 对Union封闭

    $N_1\cup N_2=(V_1\cup V_2\cup{S},\Sigma_1\cup\Sigma_2,R_1\cup R_2\cup{S\to S_1,S\to S_2},S)$

  2. 对Concat封闭

    $N_1 N_2=(V_1\cup V_2\cup{S},\Sigma_1\cup\Sigma_2,R_1\cup R_2\cup{S\to S_1S_2},S)$

  3. 对Kleen Star封闭

    $N_1^*=(V_1\cup{S},\Sigma_1,R_1\cup{S\to \epsilon,S\to SS_1},S)$

  4. CFL与RL的交集是CFL

  5. CFL与CFL的交集不一定是CFL

  6. 对补集也不封闭

2.7 Pumping Lemma

类似于RL的pumping lemma，用于证明不是CFL

对每个无限 CFL $L$，存在一个常数 $p \ge 1$（称为“pumping length”），使得

对任意长度 $≥ p$ 的字符串 $s \in L$，都可以写成：$s = uvwxy$，并满足：

  1. $|vwx| \le p $（“中间区段不长”）
  2. $|vx| \ge 1$ （“v 和 x 至少有一个非空”）
  3. 对所有$i \ge 0$，$uv^i w x^i y \in L$（重复 $v$ 和 $x$ 字符串$i$ 次，生成的串仍在 $L$ 中）

证明使用抽屉原理

同样具有反例：

$L={a^ib^jc^kd^l|a=0\or j=k=l}$

2.8 三个问题

Q1: Acceptance: $w\in L(A)$？

可以解决，转换为Chomsky范式，就必然能够在有限步内识别完

Q2: Emptiness: $L(A)=\varnothing$?

可以解决，不断扩增所有“可生成变量”

Q3: Equality: $L(A)=L(B)$?

不可以解决

2.9 DPDA & DCFL

就是确定PDA和确定CFL

类似DCFL和CFL关系类似于DFA和NFA

但是DCFL和CFL是不等价的

DCFL对补集是封闭的

不具有模糊性

能写成LR(k)文法（使用DK-test检测）

3 Turing Machine

3.1 Definition

7元组,$(Q,\Sigma,\Gamma,\delta,q_0,q_\text{accept},q_\text{reject})$, where $Q,\Sigma,\Gamma$ are all finite and

  1. $Q$ is a set of states,
  2. $\Sigma$ is the input alphabet not containing the blank symbol $\sqcup$,
  3. $\Gamma$ is the tape alphabet, where $\sqcup∈\Gamma$ and $\Sigma \subseteq\Gamma$,
  4. $\delta: Q×\Gamma →Q×\Gamma ×{L,R}$is the transition function, (L, R means to move left/right after current step)
  5. $q_0 \in Q$ is the start state,
  6. $q_\text{accept} \in Q$ is the accept state, and
  7. $q_\text{reject}\in Q$ is the reject state, where $q_\text{reject}\ne q_\text{accept}$.

有三种终止状态

  1. accept
  2. reject
  3. Non-halting

3.2 Variants of Turing Machine

Multitape Turing Machines

$δ: Q×\Gamma^k →Q×\Gamma^k ×{L,R,S}^k$

多带图灵机与单带图灵机等价

Non-deterministic Turing Machine

$\delta:Q\times \Gamma\to\mathcal P(Q\times \Gamma\times{L,R})$

与确定图灵机等价

  • 确定图灵机相当于宽度优先遍历非确定图灵机的树
  • 不能深度优先遍历是因为会有死循环的情况

Enumerator

打印出自己所有可接受结果的机器

也与图灵机等价

4 Decidability

整理

  • Decidable:
    • $A_\text{DFA}={\langle B,w\rangle|B\text{ is a DFA that accepts input string }w}$
    • $A_\text{NFA}={\langle B,w\rangle|B\text{ is an NFA that accepts input string }w}$
    • $A_\text{REX}={\langle R,w\rangle|R\text{ is a regular expression that generates }w}$
    • $E_\text{DFA}={\langle A\rangle|A\text{ is a DFA and }L(A)=\varnothing}$
    • $EQ_\text{DFA}={\langle A,B\rangle|A\text{ and }B\text{ are DFAs and }L(A)=L(B)}$
    • $A_\text{CFG}={\langle G,w\rangle|G \text{ is a CFG that generates }w}$
    • $E_\text{CFG}={\langle G\rangle|G\text{ is a CFG and }L(G)=\varnothing}$
    • $A_\text{LBA}={\langle M,w\rangle|M\text{ is an LBA that accepts }w}$
  • Recognizable
    • $A_\text{TM}={\langle M,w\rangle|M\text{ is a TM and }M\text{ accepts } m}$
    • $HALT_\text{TM}={\langle M,w\rangle|M \text{ is a TM and }M\text{ halts on input } w}$
  • co-Recognizable
    • $E_\text{TM}={\langle M\rangle|M\text{ is a TM and }L(M)=\varnothing}$
    • $EQ_\text{CFG}={\langle G,H\rangle|G \text{ and } H\text{ are CFGs and }L(G)=L(H)}$
  • not Recognizable and co-Recognizable
    • $EQ_\text{TM}={\langle A,B\rangle|A\text{ and }B\text{ are TMs and }L(A)=L(B)}$
    • $REGULAR_\text{TM}={\langle M\rangle|M\text{ is a TM and }L(M)\text{ is a regular language}}$
    • $E_\text{LBA}={\langle M\rangle|M\text{ is an LBA and }L(M)=\varnothing}$
    • $ALL_\text{CFG}$

$\text{Decidabe}=\text{Recognizable}\cap \text{co-Recognizable}$

？→ $\exists$ → $\forall$

连续的 $\exists$ / $\forall$多个视作一个 $\exists$ / $\forall$

$\forall$越多，复杂性越大

$A_\text{TM} = {⟨M,w⟩|M\text{ is a TM and }M\text{ accepts }w}$是undecidable但是recognizable的

${\overline{A_\text{TM}}} = {⟨M,w⟩|M\text{ is a TM and }M\text{ rejects }w}$是unrecognizable的，称为co-turing recognizable

对于1的证明，可以通过构造$D$，$D(\langle M\rangle)=\begin{cases}\text{accept if }M\text{ does not accept }\langle M\rangle,\\text{reject if }M\text{ accepts }\langle M\rangle,\end{cases}$

那么$D\langle D\rangle$就是一个悖论

对于2的证明，讨论一下$L$和$\bar L$在$A_\text{TM}$和$\overline{ A_\text{TM}}$接受的情况即可

5 Reducibility

用规约了证明问题

Undecidable Problems for Language Theory

$HALT_\text{TM}$

$HALT_\text{TM} = {\langle M,w\rangle|M\text{ is a TM and } M\text{halts on input } w}$ is undecidable

将其直接归约为$A_\text{TM}$即可

$E_\text{TM}$

$E_{TM}={\langle M\rangle|M\text{ is a TM and }L(M)=\varnothing }$ is undecidable

构造一个$A’\text{TM}$，参数为$A\text{TM}(M,w)$，输入为$x$

在$A_\text{TM}(M,w)$接受时接受，拒绝时拒绝

所以输出与$x$无关，可接受的是全集或者空集

因为$A_\text{TM}$是undecidable的，所以$E_\text{TM}$也是undecidable的

$Regular_\text{TM}$

$Regular_\text{TM}={\langle M\rangle|M\text{ is a TM and } L(M)\in RL}$ is undecidable

构造一个$S_{m,w}(x)$

如果$x=0^n1^n$ accept

如果$x\ne 0^n1^n$ return $A_\text{TM}(M,w)$

$\therefore L(S)=\begin{cases}\Sigma^* & \langle M,w\rangle\in A_\text{TM}\{0^n1^n}&\langle M,w\rangle\notin A_\text{TM}\end{cases}$

$\therefore \langle M,w\rangle\in A_\text{TM}\Leftrightarrow S\in Regular_\text{TM}$

所以是undecidable的

$EQ_\text{TM}$

$EQ_\text{TM} = {\langle M_1,M_2\rangle|M_1\text{ and }M_2\text{ are TMs and } L(M_1)=L(M_2)}$

取特例，令$M_2$为空，归约到$E_\text{TM}$即可

Reductions via computation histories

定义计算历史$C_1,\cdots, C_l$根据最后一个状态是accept还是reject定义它是接受/拒绝的计算历史

Linear Bounded Automata: 一个图灵机，但是指针只能在输入的范围上移动

$A_\text{LBA}$ is decidable

虽然LBA本身有无限的状态，但是给定输入之后，LBA的状态就是有限的，所以它是decidable的

$E_\text{LBA}$

$E_{LBA}$ is undecidable，也通过$A_\text{TM}$来归约

构造$B_{m,w}$，s.t. $\langle M,w\rangle\in A_\text{TM}\Leftrightarrow L(B_{m,w})\ne \varnothing$

定义$B_{m,w}(x) = B_\text{accept} \iff x \text{ is an accepting hostory of }M\text{ on }w$

直观来看，就是因为LBA无法在有限的空间里模拟$A_\text{TM}$，所以直接把$A_\text{TM}$的计算过程展开作为$B_\text{TM}$的输入，这样就可以放得下了

$ALL_\text{CFG}$

$ALL_\text{CFG} = {\langle G\rangle|G \text{ is an CFG and }L(G)=\Sigma^*}$ is undecidable

$ALL_\text{CFG}\text{ is undecidable}\iff \overline{ALL_\text{CFG}} \text{ is undecidable}$

下证$A_\text{TM}\leq \overline{ALL_\text{CFG}}$

接受计算历史 H 的格式： H=#C1#C2#…#Cℓ#。

G 需要生成所有不符合 H 特征的字符串。这些字符串不符合 H 的原因分为三类：

  1. 无效开始 C1： 字符串不以 M 在 w 上的起始配置 C1 开头。
  2. 无效结束 Cℓ： 字符串不以 M 的接受配置结束。
  3. 非法转移 Ci\⊢Ci+1： 字符串中至少有一对**相邻配置 Ci#Ci+1 不满足 M 的转移规则。

G 识别的语言 L(G) 是识别这三类错误的语言的并集。前两类容易用 CFG 实现，第三类是关键。

通过构造一个合适的PDA来实现这一点，但是堆栈会有问题

让奇数位Ci保持正序编码，偶数位保持逆序编码

Mapping Reducibility

函数的定义：$\Sigma^\to\Sigma^$，对于图灵机$M$，对于每一个输入$w$，终止时tape上的是$f(w)$

定义mapping reducibility $A\leq_m B$: $\exists$ a computable function $f,\forall w\in\Sigma^*,w\in A\iff f(w)\in B$

$A\leq_m B\iff\bar A\leq_m\bar B$:

  1. $B$ decidable $\to$ $A$ decidable
  2. $A$ undecidable $\to$ $B$ undecidable
  3. $B$ turing-recognizable $\to$ $A$ turing-recognizable
  4. $A$ not turing-recognizable $\to$ $B$ not turing-recognizable

强大武器：Rice Theroem

任何关于图灵机所识别语言的非平凡性质，都是不可判定的。

两个核心前提：

  • 是关于语言的性质（Property of Language）： 该性质只取决于图灵机接受哪些字符串，即如果 L(M1)=L(M2)，那么它们必须同时具备或不具备该性质。
  • 它是非平凡的（Non-trivial）： 这个性质既不是“永远成立”的，也不是“永远不成立”的。

证明思路：

  • 定义

    • 我现在有一个性质语言的性质$p$，满足$P_\text{TM}(x)={x|x是一个满足p的语言}$，设$Q\in P_\text{TM}$，$\varnothing\notin P_\text{TM}$（如果属于则证明其补语言是undecidable的），$Q$对应的图灵机是$M_q$
    • 如果$P_\text{TM}$是decidable的，设它的判断器为$R$

  • 现在开始把$P_\text{TM}$规约到$A_\text{TM}$：

    • 要测试$A(M,w)$的 时候，构造辅助TM $M_w$ ，$M_w(x)$定义为:

      运行$M(w)$，

      1. 如果接受，则运行$M_q(x)$，$M_q$接受则$M_w$接受，$M_q$不接受则$M_w$不接受
      2. 如果不接受或者循环，则$M_w$不接受

  • 这样以来可以通过$R$构造$A_\text{TM}$的判别器$S$

    • 如果$R(M_w)$接受，则$M_w$接受
    • 如果$R(M_w)$不接受，则$M_w$不接受

9 Intractability

Hierarchy Theorems

Space constructible

判断一个算法是否是$O(f(n))$的，计算算法复杂度的算法的复杂度本身，也必须是$O(f(n))$的

如果$f(n)$是$o(n)$的，就使用工作带只读带的逻辑（类似LSPACE）

Space hierarchy theorem

对于任何空间可构造函数 $f(n)$，一定存在一个语言（即一个问题）A，它：

  • 可以用 $O(f(n))$ 的空间解决。
  • 不可能用 $o(f(n))$ 的空间解决（即增长速度严格慢于 $f(n)$ 的空间都不行）。

同理，也有时间层次定理

Relativization

假设有神谕oracle，能够在$O(1)$下解决某一类问题时，各类不同问题的复杂性

Circuit

电路复杂性

时间复杂度$O(t(n))$，电路复杂性$O(t^2(n))$

1.1 Deterministic Finite Automata (DFA)

Definition: 5-tuple $(Q,\Sigma,\delta,q_0,F)$

  1. (Q) is a finite set called the states
  2. (\Sigma) is a finite set called the alphabet
  3. (\delta: Q \times \Sigma \to Q) is the transition function
  4. (q_0 \in Q) is the start state
  5. (F \subseteq Q) is the set of accept states

Note that in point 3, every element in (Q) must have such a function defined with every element in $\Sigma$.

1.2 Nondeterministic Finite Automata (NFA)

Also a 5-tuple $(Q,\Sigma,\delta,q_0,F)$, but point 3 is different:

  1. (Q) is a finite set called the states,
  2. (\Sigma) is a finite set called the alphabet,
  3. (\delta: Q \times \Sigma_\epsilon \to \mathcal{P}(Q)) is the transition function, where (\Sigma_\epsilon = \Sigma \cup {\epsilon}),
  4. (q_0 \in Q) is the start state,
  5. (F \subseteq Q) is the set of accept states.

1.3 DFA & NFA

For any NFA, there exists an equivalent DFA.

Use the set of NFA nodes as the nodes of the DFA.

$(Q,\Sigma,\delta,q_0,F)\to(P(Q),\Sigma,\delta’,E(q_0),F’)$

  1. $Q\to P(Q)$ take the power set

  2. $\delta\to\delta’:\delta’(R,a)=\bigcup{E(q)|q\in Q\wedge(\exists r\in R)(q\in \delta(r,a))}$

  3. $q_0\to E(q_0)$

    initially set E(q) = {q};
    repeat
        E′(q) = E(q)
        ∀x∈E(q),if ∃y∈δ(x,ϵ) ∧y̸∈E(q),E(q) = E(q) ∪{y}
    until E(q) = E′(q)
return E(q)

  4. $F’={R\in Q’|R\cap F\ne\varnothing}$

1.4 Regular

A language is called regular if some finite automata recognizes it.

Operations that are closed:

  • Union：$A\cup B={x|x\in A\vee x\in B}$
  • Concatenation: $A\circ B={xy|x\in A\wedge y\in B}$
  • Kleene Star: $A^*={x_1x_2\cdots x_k|k\geq 0 \wedge x_i\in A}$
  • Complement: $\bar A={x|x\notin A}$

Note:

$(01)^\epsilon=(01)^$

$(01)^*\varnothing=\varnothing$

** $\varnothing^\ast={\epsilon}$**

1.5 Pumping Lemma

To prove a language is not regular: pumping lemma
For every infinite regular language $L$, there exists a constant $p \ge 1$ (pumping length), such that
for any string $s \in L$ with $|s| \ge p$, $s$ can be written as $s = xyz$, satisfying:

  1. $|xy| \le p $ (within the first p characters, x and y are contained)
  2. $|y| \ge 1$ (y is at least non-empty)
  3. For all $i \ge 0$, $xy^i z \in L$

To prove a language is regular: construct a DFA or NFA.

Satisfying the pumping lemma is a necessary but not sufficient condition for regular languages.

The proof of the pumping lemma uses the pigeonhole principle.

It is only a necessary condition, not sufficient. Counterexamples that satisfy the Pumping Lemma but are not regular:

  1. $L={a^nb^nc^n}\cup{a^ib^jc^k|i,j,k\text{ not all equal}}$
  2. $L={a^ib^jc^j|i\geq1,j\geq0}\cup{b^ic^j|i,j\geq0}$
  3. $L={a^ib^jc^k|i=0\ \text{or}\ j=k}$

1.6 Three Questions

Q1: Acceptance: $w\in L(A)$?

Decidable. Just simulate the computation.

Q2: Emptiness: $L(A)=\varnothing$?

Decidable. Check whether all possible paths can reach an accept state.

Q3: Equality: $L(A)=L(B)$?

Decidable.

$\Leftrightarrow L(A)\oplus L(B)=\varnothing$

2 Context Free Languages

2.1 Definition

Definition: 4-tuple $(V,\Sigma,R,S)$

  1. $V$ is a finite set called the variables,
  2. $\Sigma$ is a finite set, disjoint from V, called the terminals,
  3. $R$ is a finite set of rules, with each rule being a variable and a string of variables and terminals,
  4. $S\in V$ is the start variable.

2.2 Ambiguity

  1. Specify precedence: Leftmost Derivation, expand the leftmost variable first.

But this still cannot resolve ambiguity. The remaining ambiguity is called genuine ambiguity.

In fact:

  1. There is no algorithm to remove the ambiguity of a CFG.
  2. There is no algorithm to determine whether any CFG is ambiguous.

2.3 Chomsky Normal Form

Definition:

  1. Only allows $A\to BC$ or $A\to a$, where $a$ is a terminal, and $B$, $C$ are variables other than the start variable.
  2. Allows $S\to\epsilon$, where $S$ is the start variable.

Theorems:

  1. Every CFG can be converted to Chomsky Normal Form.
  2. $\forall G\in\text{CFG},w\in L(G),w\ne\epsilon$ can be derived from the start symbol in exactly $2|w|-1$ steps.

2.4 Pushdown Automata (PDA)

The machine corresponding to CFG is the Pushdown Automaton.

Definition: 6-tuple $(Q,\Sigma,\Gamma,\delta,q_0,F)$

  1. $Q$ is a finite set of states,
  2. $\Sigma$ is a finite set of input alphabet,
  3. $\Gamma$ is a finite set of stack alphabet,
  4. $\delta$: $Q×\Sigma_ϵ ×\Gamma_ϵ →\mathcal P(Q×\Gamma_ϵ)$ is the transition function,
  5. $q_0 ∈Q$ is the start state,
  6. $F ⊆Q$ is the set of accept states.

Essentially, it’s a process of pushing and popping from a stack.

There needs to be a bottom-of-stack symbol that gets pushed first to mark the stack bottom.

2.5 CFG Equivalent to PDA

  • Given a CFG, construct a PDA: draw the state transition diagram.

  • Given a PDA, construct a CFG:

    • Simplify the PDA

      • Only one accept state
      • The stack is empty upon acceptance
      • Each transition either pushes one symbol or pops one symbol (not both)

    • Construct the CFG by cases

      Given $(Q, Σ, Γ, δ, q_0, q_{accept})$. We construct CFL $G$.
      with variables set ${A_{pq} | p, q ∈ Q}$, start variable $A_{q_0,q_{accept}}$. The rules are as follows:

      1. For each $p, q, r, s ∈ Q$, $u ∈ \Gamma$, and $a, b ∈ \Sigma_ε$, if
        $(r, u) ∈ δ(p, a, ε)$ and $(q, ε) ∈ δ(s, b, u)$, put the rule
        $A_{pq} → a A_{rs} b$ in $G$.
      2. For each $p, q, r ∈ Q$, put the rule $A_{pq} → A_{pr} A_{rq}$ in $G$.
      3. Finally, for each $p ∈ Q$, put the rule $A_{pp} → ε$ in $G$

2.6 Properties

  1. Closed under Union

    $N_1\cup N_2=(V_1\cup V_2\cup{S},\Sigma_1\cup\Sigma_2,R_1\cup R_2\cup{S\to S_1,S\to S_2},S)$

  2. Closed under Concatenation

    $N_1 N_2=(V_1\cup V_2\cup{S},\Sigma_1\cup\Sigma_2,R_1\cup R_2\cup{S\to S_1S_2},S)$

  3. Closed under Kleene Star

    $N_1^*=(V_1\cup{S},\Sigma_1,R_1\cup{S\to \epsilon,S\to SS_1},S)$

  4. The intersection of a CFL and a regular language is a CFL.

  5. The intersection of two CFLs is not necessarily a CFL.

  6. Not closed under complement.

2.7 Pumping Lemma

Similar to the pumping lemma for regular languages, used to prove a language is not context-free.

For every infinite CFL $L$, there exists a constant $p \ge 1$ (called the “pumping length”), such that

for any string $s \in L$ with length $≥ p$, $s$ can be written as $s = uvwxy$, satisfying:

  1. $|vwx| \le p $ (the “middle section is not too long”)
  2. $|vx| \ge 1$ (at least one of $v$ and $x$ is non-empty)
  3. For all $i \ge 0$, $uv^i w x^i y \in L$ (repeating $v$ and $x$ $i$ times still gives a string in $L$)

The proof uses the pigeonhole principle.

There are also counterexamples:

$L={a^ib^jc^kd^l|i=0\ \text{or}\ j=k=l}$

2.8 Three Questions

Q1: Acceptance: $w\in L(A)$?

Decidable. Convert to Chomsky Normal Form, then it can definitely be parsed in finitely many steps.

Q2: Emptiness: $L(A)=\varnothing$?

Decidable. Repeatedly expand the set of “generative variables”.

Q3: Equality: $L(A)=L(B)$?

Undecidable.

2.9 DPDA & DCFL

Deterministic PDA and deterministic CFL.

The relationship between DCFL and CFL is analogous to the relationship between DFA and NFA.

But DCFL and CFL are not equivalent.

DCFL is closed under complement.

DCFLs are unambiguous.

Can be written as LR(k) grammars (tested using the DK-test).

3 Turing Machine

3.1 Definition

7-tuple $(Q,\Sigma,\Gamma,\delta,q_0,q_\text{accept},q_\text{reject})$, where $Q,\Sigma,\Gamma$ are all finite and

  1. $Q$ is a set of states,
  2. $\Sigma$ is the input alphabet not containing the blank symbol $\sqcup$,
  3. $\Gamma$ is the tape alphabet, where $\sqcup∈\Gamma$ and $\Sigma \subseteq\Gamma$,
  4. $\delta: Q×\Gamma →Q×\Gamma ×{L,R}$ is the transition function, (L, R means to move left/right after current step)
  5. $q_0 \in Q$ is the start state,
  6. $q_\text{accept} \in Q$ is the accept state, and
  7. $q_\text{reject}\in Q$ is the reject state, where $q_\text{reject}\ne q_\text{accept}$.

There are three ways to halt:

  1. accept
  2. reject
  3. Non-halting

3.2 Variants of Turing Machine

Multitape Turing Machines

$δ: Q×\Gamma^k →Q×\Gamma^k ×{L,R,S}^k$

Multitape Turing machines are equivalent to single-tape Turing machines.

Non-deterministic Turing Machine

$\delta:Q\times \Gamma\to\mathcal P(Q\times \Gamma\times{L,R})$

Equivalent to deterministic Turing machines.

  • A deterministic Turing machine corresponds to a breadth-first traversal of the non-deterministic machine’s computation tree.
  • Depth-first traversal is not used because it might get stuck in infinite loops.

Enumerator

A machine that prints out all the strings it accepts.

Also equivalent to a Turing machine.

4 Decidability

Summary:

  • Decidable:
    • $A_\text{DFA}={\langle B,w\rangle|B\text{ is a DFA that accepts input string }w}$
    • $A_\text{NFA}={\langle B,w\rangle|B\text{ is an NFA that accepts input string }w}$
    • $A_\text{REX}={\langle R,w\rangle|R\text{ is a regular expression that generates }w}$
    • $E_\text{DFA}={\langle A\rangle|A\text{ is a DFA and }L(A)=\varnothing}$
    • $EQ_\text{DFA}={\langle A,B\rangle|A\text{ and }B\text{ are DFAs and }L(A)=L(B)}$
    • $A_\text{CFG}={\langle G,w\rangle|G \text{ is a CFG that generates }w}$
    • $E_\text{CFG}={\langle G\rangle|G\text{ is a CFG and }L(G)=\varnothing}$
    • $A_\text{LBA}={\langle M,w\rangle|M\text{ is an LBA that accepts }w}$
  • Recognizable:
    • $A_\text{TM}={\langle M,w\rangle|M\text{ is a TM and }M\text{ accepts }w}$
    • $HALT_\text{TM}={\langle M,w\rangle|M \text{ is a TM and }M\text{ halts on input } w}$
  • co-Recognizable:
    • $E_\text{TM}={\langle M\rangle|M\text{ is a TM and }L(M)=\varnothing}$
    • $EQ_\text{CFG}={\langle G,H\rangle|G \text{ and } H\text{ are CFGs and }L(G)=L(H)}$
  • Not Recognizable nor co-Recognizable:
    • $EQ_\text{TM}={\langle A,B\rangle|A\text{ and }B\text{ are TMs and }L(A)=L(B)}$
    • $REGULAR_\text{TM}={\langle M\rangle|M\text{ is a TM and }L(M)\text{ is a regular language}}$
    • $E_\text{LBA}={\langle M\rangle|M\text{ is an LBA and }L(M)=\varnothing}$
    • $ALL_\text{CFG}$

$\text{Decidable}=\text{Recognizable}\cap \text{co-Recognizable}$

$?$ → $\exists$ → $\forall$

Consecutive $\exists$ / $\forall$ quantifiers can be treated as a single $\exists$ / $\forall$.

The more $\forall$ quantifiers, the higher the complexity.

$A_\text{TM} = {⟨M,w⟩|M\text{ is a TM and }M\text{ accepts }w}$ is undecidable but recognizable.

${\overline{A_\text{TM}}} = {⟨M,w⟩|M\text{ is a TM and }M\text{ rejects }w}$ is unrecognizable, called co-turing recognizable.

For the proof of (1), construct $D$, where $D(\langle M\rangle)=\begin{cases}\text{accept if }M\text{ does not accept }\langle M\rangle,\\text{reject if }M\text{ accepts }\langle M\rangle,\end{cases}$

Then $D\langle D\rangle$ gives a contradiction.

For the proof of (2), discuss the cases where $L$ and $\bar L$ are accepted by $A_\text{TM}$ and $\overline{ A_\text{TM}}$, respectively.

5 Reducibility

Use reduction to prove undecidability.

Undecidable Problems for Language Theory

$HALT_\text{TM}$

$HALT_\text{TM} = {\langle M,w\rangle|M\text{ is a TM and } M\text{halts on input } w}$ is undecidable.

Reduce it directly from $A_\text{TM}$.

$E_\text{TM}$

$E_{TM}={\langle M\rangle|M\text{ is a TM and }L(M)=\varnothing }$ is undecidable.

Construct an auxiliary $A’\text{TM}$ that takes $A\text{TM}(M,w)$ as a parameter, and takes $x$ as input.

It accepts when $A_\text{TM}(M,w)$ accepts, rejects when $A_\text{TM}(M,w)$ rejects.

Thus the output is independent of $x$; the accepted language is either $\Sigma^*$ or $\varnothing$.

Since $A_\text{TM}$ is undecidable, $E_\text{TM}$ is also undecidable.

$Regular_\text{TM}$

$Regular_\text{TM}={\langle M\rangle|M\text{ is a TM and } L(M)\in RL}$ is undecidable.

Construct $S_{m,w}(x)$:

If $x=0^n1^n$, accept.

If $x\ne 0^n1^n$, return $A_\text{TM}(M,w)$.

$\therefore L(S)=\begin{cases}\Sigma^* & \langle M,w\rangle\in A_\text{TM}\{0^n1^n}&\langle M,w\rangle\notin A_\text{TM}\end{cases}$

$\therefore \langle M,w\rangle\in A_\text{TM}\Leftrightarrow S\in Regular_\text{TM}$

Therefore it is undecidable.

$EQ_\text{TM}$

$EQ_\text{TM} = {\langle M_1,M_2\rangle|M_1\text{ and }M_2\text{ are TMs and } L(M_1)=L(M_2)}$

Take the special case where $M_2$ is an empty machine, reducing to $E_\text{TM}$.

Reductions via Computation Histories

Define a computation history $C_1,\cdots, C_l$. Depending on whether the last state is an accept or reject state, it is called an accepting or rejecting computation history.

Linear Bounded Automata: a Turing machine whose head can only move within the input region.

$A_\text{LBA}$ is decidable.

Although an LBA has infinitely many possible configurations, once the input is fixed, the number of configurations is finite, so it is decidable.

$E_\text{LBA}$

$E_{LBA}$ is undecidable, also proven by reducing from $A_\text{TM}$.

Construct $B_{m,w}$ such that $\langle M,w\rangle\in A_\text{TM}\Leftrightarrow L(B_{m,w})\ne \varnothing$.

Define $B_{m,w}(x) = B_\text{accept} \iff x \text{ is an accepting history of }M\text{ on }w$.

Intuitively, since an LBA cannot simulate $A_\text{TM}$ in finite space, we unfold the computation of $A_\text{TM}$ as the input to $B_{m,w}$, so it fits within the bounded space.

$ALL_\text{CFG}$

$ALL_\text{CFG} = {\langle G\rangle|G \text{ is a CFG and }L(G)=\Sigma^*}$ is undecidable.

$ALL_\text{CFG}\text{ is undecidable}\iff \overline{ALL_\text{CFG}} \text{ is undecidable}$.

We prove $A_\text{TM}\leq \overline{ALL_\text{CFG}}$.

Format of an accepting computation history H: H=#C1#C2#…#Cℓ#.

G needs to generate all strings that do NOT match the format of H. There are three categories of strings that fail to be a valid history:

  1. Invalid start C1: The string does not begin with the starting configuration C1 of M on w.
  2. Invalid end Cℓ: The string does not end with an accepting configuration of M.
  3. Invalid transition Ci⊬Ci+1: The string contains at least one pair of adjacent configurations Ci#Ci+1 that does not satisfy the transition rule of M.

The language L(G) recognized by G is the union of languages recognizing these three types of errors. The first two are easy to implement with a CFG; the third is the crucial one.

This can be done by constructing a suitable PDA, but the stack poses some issues.

Encode odd-indexed configurations Ci in their original order, and even-indexed configurations in reverse order.

Mapping Reducibility

Definition of a function: $\Sigma^\to\Sigma^$. For a Turing machine $M$, for every input $w$, when it halts, what’s on the tape is $f(w)$.

Define mapping reducibility $A\leq_m B$: $\exists$ a computable function $f,\forall w\in\Sigma^*,w\in A\iff f(w)\in B$.

$A\leq_m B\iff\bar A\leq_m\bar B$:

  1. $B$ decidable $\to$ $A$ decidable
  2. $A$ undecidable $\to$ $B$ undecidable
  3. $B$ turing-recognizable $\to$ $A$ turing-recognizable
  4. $A$ not turing-recognizable $\to$ $B$ not turing-recognizable

Powerful Weapon: Rice’s Theorem

Any non-trivial property of the language recognized by a Turing machine is undecidable.

Two core prerequisites:

  • It is a property of the Language: The property depends only on which strings the Turing machine accepts, i.e., if $L(M_1)=L(M_2)$, then either both or neither have the property.
  • It is Non-trivial: The property is neither “always true” nor “always false”.

Proof sketch:

  • Definitions:

    • Suppose we have a property $p$ of languages, with $P_\text{TM}(x)={x|x\text{ is a language satisfying property }p}$. Let $Q\in P_\text{TM}$, and $\varnothing\notin P_\text{TM}$ (if $\varnothing\in P_\text{TM}$, then prove the complement language is undecidable instead). Let $M_q$ be a Turing machine recognizing $Q$.
    • Suppose $P_\text{TM}$ is decidable, with decider $R$.

  • Now reduce $P_\text{TM}$ to $A_\text{TM}$:

    • To test $A(M,w)$, construct an auxiliary TM $M_w$, where $M_w(x)$ is defined as:

      Run $M(w)$,

      1. If it accepts, then run $M_q(x)$. If $M_q$ accepts, then $M_w$ accepts; if $M_q$ rejects, then $M_w$ rejects.
      2. If it rejects or loops, then $M_w$ rejects.

  • In this way, we can construct a decider $S$ for $A_\text{TM}$ using $R$:

    • If $R(M_w)$ accepts, then $M_w$ accepts.
    • If $R(M_w)$ rejects, then $M_w$ rejects.

7 Time Complexity

A language recognizable by a Turing machine within $o(n\log n)$ time is regular.

Anything a multitape Turing machine can do in $O(t(n))$ time, a single-tape Turing machine can do in $O(t^2(n))$ time.

Anything a non-deterministic Turing machine can do in $O(t(n))$ time, a deterministic Turing machine can do in $2^{O(t(n))}$ time.

P Class

P is the class of problems decidable in polynomial time on a deterministic single-tape Turing machine.

Encoding of the input: must be proportional to the logarithm of the input length (hence rejects unary encoding).

  • $PATH = {\langle G,s,t\rangle|G\text{ is a directed graph that has a directed path from }s\text{ to }t}$
  • $RELPRIME={\langle x,y\rangle|x\text{ and }y\text{ are relatively prime}}$
  • CFL

NP Class

NP problems are those acceptable in polynomial time.

NP is the class of problems decidable in polynomial time on a non-deterministic single-tape Turing machine / problems verifiable in polynomial time on a deterministic single-tape Turing machine.

  • $HAMPATH={\langle G,s,t\rangle|G\text{ is a directed graph with a hamiltonian path from }s\text{ to }t}$

8 Space Complexity

Definitions:

Space(N): space complexity on a DTM.

NSpace(N): space complexity on an NTM.

We consider deciders rather than verifiers.

In terms of space complexity, PSPACE = NPSPACE.

In fact, NPSPACE(f(n)) $\subseteq$ SPACE(f²(n)).

P $\subseteq$ PSPACE.

NP $\subseteq$ NPSPACE $=$ PSPACE $\subseteq$ EXPTIME.

NPSPACE = co-NPSPACE.

Reductions in PSPACE are still polynomial-time reductions.

PSPACE-complete: TQBF.

LSPACE: the input tape (read-only) is linear, but the work tape (read-write) is $O(\log n)$.

NL $\subseteq$ P, L = co-NL, but it’s not known whether L = NL (believed not).

PATH $\in$ NLC.

NL-Complete reductions are log-space reducibility, not polynomial-time reducibility.

During the reduction, the output of A (which is the input to B) might be polynomial in size — the solution: read one character at a time; to get the next character, recompute the entire output.

9 Intractability

Hierarchy Theorems

Space Constructibility

To determine whether an algorithm runs in $O(f(n))$ time/space, the complexity of computing the algorithm’s complexity measure itself must also be $O(f(n))$.

If $f(n)$ is $o(n)$, then use the read-only work-tape logic (similar to LSPACE).

Space Hierarchy Theorem

For any space-constructible function $f(n)$, there exists a language (i.e., a problem) A such that:

  • It can be solved in $O(f(n))$ space.
  • It cannot be solved in $o(f(n))$ space (i.e., no space smaller than $f(n)$ by more than a constant factor suffices).

Similarly, there is a time hierarchy theorem.

Relativization

Assuming an oracle that can solve a certain class of problems in $O(1)$, how the complexity of various problems changes.

Circuit Complexity

Circuit complexity.

Time complexity $O(t(n))$ corresponds to circuit complexity $O(t^2(n))$.
