密码学

古典密码

代换

  • 移位密码（Caesar密码是k=3的特殊情况）

    密钥空间仅25个元素

  • 单表代换密码

    密钥空间26!种，足够大

    但是可以通过统计学解密

    • 仿射密码：单表代换密码的一种

      $e(x)=ax+b(mod 26),a,b\in Z_{26}$

  • 多表代换密码，一次加密多个字符，掩盖统计频率

    • Playfair密码：两个字母→两个字母
      • 先排成5*5矩阵
      • 一组中的两字母同行，则每个字母用该行的后一字母替代；
      • 一组中的两字母同列，则每个字母用该列的后一字母替代；
      • 非同行同列字母替代，用对角的两个字母替代
    • Hill密码：m个连续字母用m个密文字母代替，乘以密钥矩阵
    • Vigenere Cipher：
      • 密钥确定字母表的顺序，第i个字母表示使用第i个字母表
      • 依次使用字母表，周期使用密钥
    • OTP（One Time Pad）：绝对安全
      • 密钥长度与明文一样长
      • 密文可拓展（可以被修改）

置换

  • 栅栏加密：横着写竖着读
  • 换位技术：明文写为矩阵块，但是列顺序打乱

对称式密码

Feistel 密码

每一轮加密：

$E_k(L,R) = \left(R,L\oplus F(R,K)\right)$

$E_k^{-1}(L,R) = \left(R\oplus F(L,K),L\right)$

加密和解密是一样的，只不过密钥倒序

DES

DES密码使用了Feistel架构，其轮函数F和密钥构造如下：

轮函数

$F(L,K)= = P( S( E(L) \oplus K ) )$

其中$S$是一个固定公开是代换，$P$是一个固定公开的置换

密钥构造

3重DES

2DES可以用2^56^攻破（Merkle-Hellman攻击），因此使用3DES，需要2^112^攻破

3DES一般性使用$E_{k_1}\circ D_{k_2}\circ E_{k_1}$

当$k_1=k_2$时，退化为DES

Merkle-Hellman攻击：

1. 准备阶段（离线预计算）

你说得对，这步不需要知道真实的密钥。

  • 攻击者设定中间值 A=0。
  • 对于 DES 所有可能的密钥 k（共 256 个），计算什么样的明文 P 经过加密能得到 0。
  • 结果： 得到一张表，里面存了 256 组 (Pi,K1,i)，满足 EK1,i(Pi)=0。
2. 采样阶段（获取数据）
  • 这就是课件里说的“代价：256 数量级的选择明文”。
  • 攻击者获取 256 组真实的明文密文对 (P,C)。
  • 逻辑： 根据概率，这 256 组里，极大概率有一个明文 P∗，它在真实密钥 K1 的作用下，产生的中间值 A刚好就是 0。
3. 破解阶段（在线匹配）

这是你提到的“做一个 2DES”的部分，但重点在于匹配：

  1. 从密文端反推： 既然我们假设 A=0 了，那么剩下的两层加密（K2,K3）就变成了一个 2DES 过程：C=EK3(DK2(0))。
    • 注：这里课件为了简化，可能假设了 K2=K3 或者某种两重加密结构，计算量级约在 256 到 2112之间。
  2. 寻找匹配： 当你通过密文端算出一组可能的 (K2,K3) 后，你手头已经有了那个“让 A=0”的特定明文 P∗。
  3. 最终锁定： 你去第一步那张大表里，查这个 P∗ 对应的 K1 是谁

IDEA、AES、SM4

常用密码算法

密码本模式（ECB模式）

用相同密钥对各个明文组分别加密，一次处理

𝑛位明文每个𝑛位明文对应唯一密文

容易被攻击，因为相同𝑛位明文对应相同𝑛位密文

密码分组链接模式 （CBC模式）

将消息分为很多块，并通过加密进行链接。已加密

的密文分组与当前的明文分组链接在一起。

需要使用初始向量IV

加密时：

$C_{i}=E_k(P_{i}\oplus C_{i-1}),C_{-1}=\text{IV}$

解密时:

$P_{i}= D_K(C_{i}) \oplus C_{i-1},C_{-1}=\text{IV}$

  • 优点
    • 每个密文分组均依据于之前的全部分组
    • 对任意一个分组的改动都会影响后继的所有密文分组
    • 需要初始向量（IV必须随机选择）
  • 缺点
    • 如果攻击者获得了IV，可以通过预先改变IV中的某些位，使得接收者的明文中部分位被取反
    • $P_1[i] = \text{IV}[i] ⊕ E_k^{-1}(C_1[i])$
    • 解决方法：在发送消息前用ECB来保护IV
    • 会受到选择密文攻击

密码反馈模式（CFB）

类似CBC

加密：

$C_i= P_i \oplus E_K(C_{i-1}), C_{-1}=\text{IV}$

解密：

$P_i=C_i \oplus E_K(C_{i-1}),C_{-1}=\text{IV}$

输出反馈模式（OFB）

加密：

$C_i= P_i \oplus O_i$

$O_i=E_K(O_{i-1}),O_0=\text{IV}$

解密：

$P_i= C_i \oplus O_i$

$O_i=E_K(O_{i-1}),O_0=\text{IV}$

优点

  • 传输过程中，比特差错不会扩散
  • 可以预计算分组，流加密时不需停顿

缺点

  • 对抗消息流篡改攻击的能力弱于CFB：若对密文取反，则解密后的明文也取反，可以看作是一次一密的变形（Vernam密码），所以绝对不能重复使用相同的密钥序列和IV
  • 发送方和接收方必须同步

计数器模式（CTR）

类似OFB

对每个明文，必须使用不同的分组密钥和计算器值（类似OTP，绝不重用）

可以并行处理

$C_i= P_i \oplus O_i$

$O_i = E_K(\text{Counter++})$

优点

  • 高效
    • 可以并行处理多块明文密文
    • 可以预计算
    • Good for bursty high speed links
  • 随机访问：密文的第i个分组可以随机访问，不需知道前面i-1个密文组（比较：CBC）
  • 可证安全：是CPA安全的
    • 前提：使用了真正的随机数生成器生成counter的起始值，并且绝不重用

缺点

  • 密钥、计数器值绝不能重用

随机数

随机性测试

  • 测试特征
    • 均匀性：0或1出现的概率和量大致相等
    • 可伸缩性：测试可以用于子序列
    • 一致性：测试针对所有的初始值
  • NIST SP800-22给出了15种测试方法
    • 频率测试（最基本）：0/1个数与真随机序列的期望大致相等
    • Maurer通用统计测试：测试是否可以大幅压缩数据且不损失信息
  • 不可预测程度
    • 前向不可预测性：不知道种子，无法依据已有bit预测下一bit
    • 后向不可预测性：从序列无法推出种子值

伪随机数生成器：

  • 形式化定义：
  • 指任意多项式时间算法，都不能以不可忽略的概率区分𝐺(𝑠)所产生的序列 vs. 等长的真随机序列。
  • 证明：如果攻击者不能区分 PRG 输出和真随机序列，那么他也就不能区分用 PRG 加密的密文与 OTP 加密的密文。

对称保密技术

定理：完善保密系统中，明文空间的尺寸

$|M|$一定小于等于密钥空间的尺寸$|K|$ ，即$|𝐾| ≥ |𝑀|$

完善保密，但是不实用

新的安全的定义

  • 严格的安全定义（现代密码学的第一准则）：攻击者能力及攻击者成功：安全模型
  • 合理的假设（现代密码学的第二准则）：往往是数学难题
  • 严格的安全证明（现代密码学的第三准则）：严密的推理过程

一些定义

  • 有效的算法：多项式时间可以执行的算法
  • 可忽略的量：对任意多项式$p$，都存在$N$，使得对所有$n > N$，都有$f(n)<\dfrac1{p(n)}$
    • 对于加法和乘法封闭

计算安全: 没有多项式时间的攻击者能以不可忽略的概率实现攻击

IND-CPA vs IND CCA：前者只能获得挑战密文的解密结果，后者可以获得除挑战密文外，任意密文结果

散列函数（Hash函数）

$h = H(M)$, $M$是变长的消息,$h$是定长的散列值.

  • 单向性：对任意给定的码$h$, 寻求$x$使得$H(x)=h$在计算上是不可行的;
  • 弱抗碰撞性：任意给定消息x, 寻求不等于x的y, 使得H(y)= H(x)在计算上不可行
  • 强抗碰撞性：寻求对任何的(x,y)对使得H(x)=H(y)在计算上不可行

Merkle Damgard结构

实际上就和CBC模式比较像，只是使用的f函数不一样，使得该密码不可逆

长度拓展攻击：知道HASH(message)的情况下，也可以推算出HASH(Message||Append)的值

生日攻击：对输出长度为m的Hash函数，值$2^{\frac m2}$决定了该Hash函数抗穷举攻击的能力，因为超过这个值就有一半的概率能找到两个碰撞

MD5

  • 步骤1：添加填充位(一个1 和若干个0)

    在消息的最后添加适当的填充位使得数据位的长度满足

    $$
    \text {length}\equiv 448 (\mod 512)
    $$

  • 步骤2：添加长度

  • 原始消息长度（二进制位的个数），用64位表示。如果长度超过2^64^位，则仅取最低64位，即mod 2^64^。

    到此为止，我们已经得到$L$个512位的数据块：$Y_0,Y_1,\cdots,Y_{L-1}$。其长度为$L\times 512$ bits。令$N=L\times16$，令$M[0\cdots N-1]$表示以字为单位的消息表示。

  • 步骤3：初始化MD缓冲区

    一个128位MD缓冲区用以保存中间和最终散列函数的结果。它可以表示为4个32位的寄存器(A,B,C,D)。寄存器初始化为以下的16进制值。使用低端格式存储。

  • 步骤4：处理消息块（Compress函数）

    其中T[i] 是 MD5 里预先定义的一组 64 个常数，由正弦函数生成

    ROL是左移，s是左移的位数，预先固定

    F在第一轮中使用，二三四轮分别使用HGI函数，每轮有16步

    $F(B,C,D) = (B \land C) \lor (\neg B \land D)$

    $G(B,C,D) = (B \land D) \lor (C \land \neg D)$

    $H(B,C,D) = B \oplus C \oplus D$

    $I(B,C,D) = C \oplus (B \lor \neg D)$

  • 步骤5：重复步骤4，直至结束。

    $\text{Compress}(H_{i-1},H_i)$，其中$H_0={A,B,C,D}$

注：步骤四中还要打乱顺序

  • 每轮中X[0…15]恰好被使用一次
  • 轮1 保持初始顺序
  • 轮2 $\rho_2(i) \equiv (1+5i) (mod 16)$
  • 轮3 $\rho_3(i) \equiv (5+3i) (mod 16)$
  • 轮4 $\rho_4(i) \equiv 7i (mod 16)$

同余与整除

  3. 等价类和剩余系

    将整数集合$Z$分成$m$个等价类：$[0],[1],\cdots,[m-1]$

    • 模$m$的完全剩余系：$a_i\in[i]\to{a_0,a_1,\cdots,a_{m-1}}$
    • 模$m$的非负最小完全剩余系（$Z_m$）：${0,1,\cdots,m-1}$
    • 模$m$的简化剩余系：去掉模$m$的完全剩余系中，与$m$不互素的那些数，剩下的部分

  4. 欧拉定理

    若$(a,n)=1$，则$a^{\phi(n)}\equiv 1(\mod n)$

    特别地，若$n=pq$，$p$，$q$为素数时，有$a^{\phi(pq)+1}\equiv a^{(p-1)(q-1)+1}\equiv a(\mod n)$，即使$(n,a)\ne1$，等式仍成立

  5. 费马小定理

    $p$是素数，$a$是正整数，$p\nmid a$，则有$a^{p-1}\equiv 1(\mod p)$

  6. 素性测试：返回否定结论一定正确，放回肯定概率出错概率极低，执行多次之后返回肯定结论出错概率大大降低

次数和原根

  • 次数
    • $(a,m)=1$，使得$a$的幂模$m$同余循环的最小周期$k$，称为$a$模$m$的次数
    • $k\mid\Phi(m)$，但是$k=\Phi(m)$不一定成立
  • 原根
    • 若$a$模$m$的次数为$\Phi(m)$，则称$a$是模$m$的一个原根
    • $m$有原根的充要条件是$m$形如$2,4,2^np^l,p^l$，且原根个数有$\Phi(\Phi(m))个$

离散对数问题

$y\equiv g^x(\mod m)$，则$x=\log_gy(\mod m)$

由x,g,m计算y容易，但是由y,g,m计算x非常困难

一些抽象代数

  • 群：封闭性、结合律、单位元、逆元

    • 交换群：群+交换律
    • 有限群：群+元素个数有限
    • 循环群：所有元素可以通过生成元自乘得到

  • 环 (Ring)：集合 R 定义了加法 (+) 和乘法 (×)：

    1. (R, $+$) 必须是一个交换群（单位元是 0）。
    2. (R, $\times$) 满足结合律（不要求有单位元，也不要求可交换）。
    3. 分配律：a(b+c)=ab+ac

    • 交换环：满足乘法交换律 (ab=ba)

    • 含单位元环：存在乘法单位元（通常记为 1）。

    • 整环 (Integral Domain)：

      • 是一个交换环。
      • 有乘法单位元 1。
      • 无零因子：即若 ab=0，则必有 a=0 或 b=0。

  • 域：整环+每个元素都有乘法逆元

    • 有限域：集合内个数有限

$$
\text{群} \xrightarrow{\text{+乘法,分配律}} \text{环} \xrightarrow{\text{+交换,单位元}} \text{交换环} \xrightarrow{\text{+无零因子}} \text{整环} \xrightarrow{\text{+非零元有逆}} \text{域}
$$

公钥系统定义及RSA

仅利用对称加密，在无可信第三方，双方互不信任时，实现双方密钥交换——Merkle Puzzle

但是通信效率低

之后需要非对称算法——公钥算法

需要找到一个单向函数——找到了离散对数

非对称算法

  1. MH scheme背包问题：本质上是子集元素和——被攻破

  2. RSA算法——大模型取模，基于整数分解

    1. 选素数：随机选择两个不同的大素数 p 和 q。
    2. 算模数：计算 n=p×q。这个 n 的长度（如 2048 位）决定了加密强度。
    3. 计算欧拉函数：计算 ϕ(n)=(p−1)(q−1)。ϕ(n) 表示不超过 n 且与 n 互素的正整数个数。
    4. 选公钥指数 e：选择一个整数 e，满足 1<e<ϕ(n) 且 gcd(ϕ(n),e)=1（即 e 与 ϕ(n) 互素）。
    5. 算私钥指数 d：计算 d 使得 d≡e^−1^(modϕ(n))。这一步通常利用图片中提到的扩展欧几里得算法来求解逆元。

    结果：

    • 公开参数：大模数 n 和公钥 e。
    • 秘密参数：大素数 p,q 和私钥 d。

    加解密：

    • 加密：$C\equiv M^e\mod n$
    • 解密：$M\equiv C^d\mod n$

    攻击：

    • p,q太接近
    • 共模攻击：使用相同的n
    • 小e攻击
    • 计时攻击

  3. Diffie-Hellman密钥协商，基于离散对数

    就是直接把自己的密钥，用对方的公钥加密发送给对方

    容易被中间人攻击

  4. ElGamel加密算法

    系统参数 $p,g$

    Alice选择私钥$x_A\in F_p^*$，计算公钥$y_A\equiv g^{X_A}\mod p$

    Bob发送消息给Alice，密文$C=(C_1,C_2)$，随机选择$k\in F_p^*$

    $C_1 \equiv g^k\mod p$ $C_2\equiv y_A^k\cdot M$

    Alice解密过程：$M=\dfrac{C_2}{C_1^{x_A}}$

    • 不抗CPA/CCA攻击（实际使用的是抗的）

Chosen Plaintext Attack (CPA)安全模型
  1. C发公钥$p_k$给A

Classical Cryptography

Substitution

  • Shift Cipher (Caesar cipher is a special case with k=3)

    The key space has only 25 elements.

  • Monoalphabetic Substitution Cipher

    The key space has 26! elements, large enough.

    But it can be broken via statistical analysis.

    • Affine Cipher: a type of monoalphabetic substitution cipher

      $e(x)=ax+b\pmod{26},a,b\in Z_{26}$

  • Polyalphabetic Substitution Cipher: encrypts multiple characters at a time, hiding statistical frequencies.

    • Playfair Cipher: two letters → two letters
      • First arrange into a 5×5 matrix.
      • If the two letters in a pair are in the same row, replace each with the letter to its right in that row.
      • If the two letters are in the same column, replace each with the letter below it in that column.
      • If they are neither in the same row nor the same column, replace them with the two letters at the opposite corners of the rectangle.
    • Hill Cipher: m consecutive plaintext letters are replaced by m ciphertext letters by multiplying with a key matrix.
    • Vigenere Cipher:
      • The key determines the order of alphabets; the i-th letter indicates using the i-th alphabet.
      • Use alphabets sequentially, cycling through the key.
    • OTP (One Time Pad): unconditionally secure.
      • Key length equals plaintext length.
      • Ciphertext is malleable (can be modified).

Permutation

  • Rail Fence Cipher: write horizontally, read vertically.
  • Transposition technique: write plaintext into a matrix block, then scramble the column order.

Symmetric Ciphers

Feistel Cipher

Each round of encryption:

$E_k(L,R) = \left(R,L\oplus F(R,K)\right)$

$E_k^{-1}(L,R) = \left(R\oplus F(L,K),L\right)$

Encryption and decryption are the same, except the keys are used in reverse order.

DES

DES uses the Feistel structure. Its round function F and key schedule are as follows:

Round Function

$F(L,K)= P( S( E(L) \oplus K ) )$

where $S$ is a fixed public substitution and $P$ is a fixed public permutation.

Key Schedule

Triple DES

2DES can be broken with $2^{56}$ operations (Merkle-Hellman attack), so 3DES is used, requiring $2^{112}$ operations to break.

3DES is generally used as $E_{k_1}\circ D_{k_2}\circ E_{k_1}$.

When $k_1=k_2$, it degenerates to DES.

Merkle-Hellman Attack:

1. Preparation Phase (Offline Precomputation)

You are right; this step does not require knowing the real key.

  • The attacker sets an intermediate value A = 0.
  • For all possible DES keys k (there are $2^{56}$), compute what plaintext P would encrypt to 0.
  • Result: A table of $2^{56}$ pairs $(P_i,K_{1,i})$ such that $E_{K_{1,i}}(P_i)=0$.
2. Sampling Phase (Data Collection)
  • This is what the lecture notes call “cost: $2^{56}$ chosen plaintexts.”
  • The attacker obtains $2^{56}$ real plaintext-ciphertext pairs (P, C).
  • Logic: By probability, among these $2^{56}$ pairs, there is very likely a plaintext $P^*$ such that under the real key $K_1$, the intermediate value A happens to be 0.
3. Cracking Phase (Online Matching)

This is the “do a 2DES” part, but the key point is matching:

  1. Work backward from the ciphertext side: Since we assume A = 0, the remaining two layers of encryption $(K_2,K_3)$ become a 2DES process: $C=E_{K_3}(D_{K_2}(0))$.
    • Note: The lecture notes may simplify here by assuming $K_2=K_3$ or some two-encryption structure; the computational complexity is about $2^{56}$ to $2^{112}$.
  2. Find a match: Once you compute a possible $(K_2,K_3)$ from the ciphertext side, you already have the specific plaintext $P^*$ that makes A = 0.
  3. Final confirmation: Look up $P^*$ in the big table from step 1 to find the corresponding $K_1$.

Common Cipher Modes

Electronic Codebook Mode (ECB Mode)

Each plaintext block is encrypted independently with the same key, one block at a time.

An n-bit plaintext block maps uniquely to an n-bit ciphertext block.

Easy to attack because identical n-bit plaintext blocks produce identical n-bit ciphertext blocks.

Cipher Block Chaining Mode (CBC Mode)

Divide the message into blocks and link them through encryption. The previously encrypted ciphertext block is combined with the current plaintext block.

Requires an initialization vector IV.

Encryption:

$C_{i}=E_k(P_{i}\oplus C_{i-1}),C_{-1}=\text{IV}$

Decryption:

$P_{i}= D_K(C_{i}) \oplus C_{i-1},C_{-1}=\text{IV}$

  • Advantages
    • Each ciphertext block depends on all previous blocks.
    • Modifying any block affects all subsequent ciphertext blocks.
    • Requires an initialization vector (IV must be randomly chosen).
  • Disadvantages
    • If an attacker obtains the IV, they can flip certain bits in the decrypted plaintext by pre-flipping bits in the IV.
    • $P_1[i] = \text{IV}[i] ⊕ E_k^{-1}(C_1[i])$
    • Countermeasure: Protect the IV with ECB before sending the message.
    • Vulnerable to chosen-ciphertext attacks.

Cipher Feedback Mode (CFB)

Similar to CBC.

Encryption:

$C_i= P_i \oplus E_K(C_{i-1}), C_{-1}=\text{IV}$

Decryption:

$P_i=C_i \oplus E_K(C_{i-1}),C_{-1}=\text{IV}$

Output Feedback Mode (OFB)

Encryption:

$C_i= P_i \oplus O_i$

$O_i=E_K(O_{i-1}),O_0=\text{IV}$

Decryption:

$P_i= C_i \oplus O_i$

$O_i=E_K(O_{i-1}),O_0=\text{IV}$

Advantages

  • Bit errors during transmission do not propagate.
  • The keystream blocks can be precomputed, allowing stream encryption without pauses.

Disadvantages

  • Weaker against message stream tampering than CFB: if the ciphertext is flipped, the decrypted plaintext is also flipped. It can be seen as a variant of one-time pad (Vernam cipher), so the same key stream and IV must never be reused.
  • The sender and receiver must stay synchronized.

Counter Mode (CTR)

Similar to OFB.

For each plaintext block, a distinct key block and counter value must be used (like OTP, never reuse).

Can be processed in parallel.

$C_i= P_i \oplus O_i$

$O_i = E_K(\text{Counter++})$

Advantages

  • Efficient
    • Multiple plaintext/ciphertext blocks can be processed in parallel.
    • Counter blocks can be precomputed.
    • Good for bursty high-speed links.
  • Random access: the i-th ciphertext block can be accessed randomly without needing the previous i-1 ciphertext blocks (compare with CBC).
  • Provably secure: it is CPA-secure.
    • Prerequisite: use a true random number generator to determine the counter’s starting value, and never reuse it.

Disadvantages

  • Keys and counter values must never be reused.

Random Numbers

Randomness Tests

  • Test Characteristics
    • Uniformity: the number of 0s and 1s should be approximately equal in frequency and count.
    • Scalability: tests can apply to subsequences.
    • Consistency: tests apply to all initial values.
  • NIST SP800-22 provides 15 test methods.
    • Frequency test (most basic): the numbers of 0s/1s should be close to the expectations for a true random sequence.
    • Maurer’s universal statistical test: test whether the data can be significantly compressed without loss of information.
  • Unpredictability
    • Forward unpredictability: without the seed, one cannot predict the next bit from existing bits.
    • Backward unpredictability: one cannot derive the seed from the sequence.

Pseudorandom Number Generators:

  • Formal definition:
    • Any polynomial-time algorithm cannot distinguish the sequence produced by $G(s)$ from a truly random sequence of equal length with non-negligible probability.
  • Rationale: if an attacker cannot distinguish a PRG output from a truly random sequence, then they also cannot distinguish ciphertext encrypted with a PRG from ciphertext encrypted with OTP.

Symmetric Encryption Security Theory

Theorem: In a perfectly secure cryptosystem, the size of the plaintext space

$|M|$ must be less than or equal to the size of the key space $|K|$, i.e., $|K| \ge |M|$.

Perfectly secure, but impractical.

New security definitions

  • Strict security definitions (first principle of modern cryptography): attacker capabilities and attacker success: security models.
  • Reasonable assumptions (second principle of modern cryptography): often mathematical hard problems.
  • Rigorous security proofs (third principle of modern cryptography): rigorous reasoning processes.

Some definitions

  • Efficient algorithm: an algorithm that runs in polynomial time.
  • Negligible quantity: for every polynomial $p$, there exists $N$ such that for all $n > N$, $f(n) < \dfrac{1}{p(n)}$.
    • Closed under addition and multiplication.

Computational security: no polynomial-time attacker can achieve success with non-negligible probability.

IND-CPA vs IND-CCA: the former only allows the adversary to obtain decryptions of the challenge ciphertext; the latter allows the adversary to obtain decryptions of any ciphertext except the challenge ciphertext.

Hash Functions

$h = H(M)$, where $M$ is a variable-length message and $h$ is a fixed-length hash value.

  • Preimage resistance (one-wayness): Given any hash value $h$, it is computationally infeasible to find $x$ such that $H(x) = h$.
  • Weak collision resistance: Given any message x, it is computationally infeasible to find a y ≠ x such that $H(y) = H(x)$.
  • Strong collision resistance: It is computationally infeasible to find any pair (x, y) such that $H(x) = H(y)$.

Merkle-Damgård Structure

It is actually similar to the CBC mode, except the compression function f is different, making the hash non-invertible.

Length extension attack: given $HASH(message)$, one can compute $HASH(Message | Append)$ without knowing the message.

Birthday attack: for a hash function with output length m, the value $2^{\frac{m}{2}}$ determines the hash’s resistance to brute-force collision search, because once the number of messages exceeds this value, there is about a 50% probability of finding a collision.

MD5

  • Step 1: Append padding bits (a single 1 followed by zeros).

    Append padding bits to the message so that the data length satisfies

    $$
    \text{length}\equiv 448 \pmod{512}
    $$

  • Step 2: Append length.

    Represent the original message length in binary (number of bits) using 64 bits. If the length exceeds $2^{64}$ bits, only the least significant 64 bits are used, i.e., mod $2^{64}$.

    Now we have L 512-bit blocks: $Y_0,Y_1,\cdots,Y_{L-1}$. Their total length is $L\times 512$ bits. Let $N=L\times16$, and let $M[0\cdots N-1]$ denote the message representation in words.

  • Step 3: Initialize MD buffer.

    A 128-bit MD buffer stores the intermediate and final hash results. It can be represented as four 32-bit registers (A, B, C, D). The registers are initialized with the following hexadecimal values, stored in little-endian format.

  • Step 4: Process message blocks (Compress function).

    A_old = A
B_old = B
C_old = C
D_old = D

A_prime = B_old + ROL(A_old + F(B_old, C_old, D_old) + M[k] + T[i], s)

A = D_old
B = A_prime
C = B_old
D = C_old

    where T[i] is a set of 64 predefined constants in MD5, generated from the sine function.

    ROL is a left rotation, and s is the number of bits to rotate, both fixed in advance.

    F is used in the first round; the second, third, and fourth rounds use the functions G, H, and I respectively. Each round has 16 steps.

    $F(B,C,D) = (B \land C) \lor (\neg B \land D)$

    $G(B,C,D) = (B \land D) \lor (C \land \neg D)$

    $H(B,C,D) = B \oplus C \oplus D$

    $I(B,C,D) = C \oplus (B \lor \neg D)$

  • Step 5: Repeat step 4 until the end.

    $\text{Compress}(H_{i-1},H_i)$, where $H_0={A,B,C,D}$.

Note: In step 4, the order of words is also shuffled.

  • In each round, X[0…15] is used exactly once.
  • Round 1 keeps the initial order.
  • Round 2: $\rho_2(i) \equiv (1+5i) \pmod{16}$
  • Round 3: $\rho_3(i) \equiv (5+3i) \pmod{16}$
  • Round 4: $\rho_4(i) \equiv 7i \pmod{16}$

Number Theory

Prime Numbers

  1. There are infinitely many primes.
  2. $\pi(x)$ denotes the number of primes not exceeding x. We have:
    1. $\lim\limits_{x\to\infty}\dfrac{\pi(x)}x=0$
    2. $\lim\limits_{x\to\infty}\dfrac{\pi(x)}{\frac x{\log x}} = 1$
  3. There are infinitely many twin primes.

Congruence and Divisibility

  1. Euclidean algorithm for computing the greatest common divisor; it can also be used to find the inverse modulo an integer, in which case it is called the extended Euclidean algorithm.

  2. Unique prime factorization of integers.

  3. Equivalence classes and residue systems.

    Partition the set of integers $Z$ into m equivalence classes: $[0],[1],\cdots,[m-1]$.

    • Complete residue system modulo m: $a_i\in[i]\to{a_0,a_1,\cdots,a_{m-1}}$.
    • Least nonnegative complete residue system modulo m ($Z_m$): ${0,1,\cdots,m-1}$.
    • Reduced residue system modulo m: remove from the complete residue system those numbers that are not coprime to m; the remaining set.

  4. Euler’s theorem

    If $(a,n)=1$, then $a^{\phi(n)}\equiv 1\pmod{n}$.

    In particular, if $n=pq$ with p and q primes, then $a^{\phi(pq)+1}\equiv a^{(p-1)(q-1)+1}\equiv a\pmod{n}$; even if $(n,a)\ne1$, the identity still holds.

  5. Fermat’s little theorem

    If p is prime, a is a positive integer, and $p\nmid a$, then $a^{p-1}\equiv 1\pmod{p}$.

  6. Primality testing: a negative result is always correct; a positive result has a very small probability of being wrong. After running many tests, the probability of a false positive becomes very small.

    The Miller-Rabin probabilistic algorithm is commonly used.

  7. Chinese Remainder Theorem.

Order and Primitive Roots

  • Order
    • If $(a,m)=1$, the smallest period k such that powers of a become congruent to 1 modulo m is called the order of a modulo m.
    • $k\mid\phi(m)$, but $k=\phi(m)$ does not always hold.
  • Primitive root
    • If the order of a modulo m is $\phi(m)$, then a is called a primitive root modulo m.
    • m has a primitive root if and only if m is of the form $2,4,2^np^l,p^l$, and the number of primitive roots is $\phi(\phi(m))$.

Discrete Logarithm Problem

$y\equiv g^x\pmod{m}$, then $x=\log_g y\pmod{m}$.

Given x, g, m, computing y is easy, but given y, g, m, computing x is very hard.

Some Abstract Algebra

  • Group: closure, associativity, identity, inverse.

    • Abelian group: group + commutativity.
    • Finite group: group + finite number of elements.
    • Cyclic group: all elements can be generated by repeated multiplication of a generator.

  • Ring: a set R with addition (+) and multiplication (×):

    1. (R, $+$) must be an abelian group (identity is 0).
    2. (R, $\times$) is associative (no requirement for identity or commutativity).
    3. Distributive law: a(b+c)=ab+ac.

    • Commutative ring: multiplication is commutative (ab=ba).

    • Ring with unit: there exists a multiplicative identity (usually denoted 1).

    • Integral Domain:

      • A commutative ring.
      • Has multiplicative identity 1.
      • No zero divisors: if ab=0, then a=0 or b=0.

  • Field: integral domain + every nonzero element has a multiplicative inverse.

    • Finite field: the set has finitely many elements.

$$
\text{Group} \xrightarrow{\text{+multiplication, distributivity}} \text{Ring} \xrightarrow{\text{+commutativity, identity}} \text{Commutative Ring} \xrightarrow{\text{+no zero divisors}} \text{Integral Domain} \xrightarrow{\text{+nonzero elements have inverses}} \text{Field}
$$

Public-Key System Definition and RSA

Using only symmetric encryption, without a trusted third party and with mutual distrust, two parties can achieve key exchange via Merkle Puzzles.

However, communication efficiency is low.

Non-symmetric algorithms—public-key algorithms—were needed.

A one-way function was sought—discrete logarithm was found.

Non-symmetric Algorithms

  1. MH scheme (knapsack problem): essentially subset-sum—was broken.

  2. RSA algorithm—modular exponentiation with large numbers, based on integer factorization.

    1. Choose primes: randomly select two distinct large primes p and q.
    2. Compute modulus: n = p×q. The length of n (e.g., 2048 bits) determines the encryption strength.
    3. Compute Euler’s totient: compute ϕ(n) = (p−1)(q−1). ϕ(n) is the number of positive integers not exceeding n that are coprime to n.
    4. Choose public exponent e: choose an integer e satisfying 1 < e < ϕ(n) and gcd(ϕ(n), e) = 1 (i.e., e is coprime to ϕ(n)).
    5. Compute private exponent d: compute d such that d ≡ e^−1^ (mod ϕ(n)). This step usually uses the extended Euclidean algorithm to find the inverse.

    Result:

    • Public parameters: modulus n and public key e.
    • Secret parameters: primes p, q and private key d.

    Encryption/Decryption:

    • Encryption: $C\equiv M^e\pmod{n}$
    • Decryption: $M\equiv C^d\pmod{n}$

    Attacks:

    • p and q too close.
    • Common modulus attack: using the same n.
    • Small e attack.
    • Timing attack.

  3. Diffie-Hellman key agreement, based on discrete logarithm.

    It essentially means sending your own key encrypted with the other party’s public key.

    Vulnerable to man-in-the-middle attacks.

  4. ElGamal encryption algorithm.

    System parameters: p, g.

    Alice chooses private key $x_A\in F_p^*$ and computes public key $y_A\equiv g^{X_A}\pmod{p}$.

    Bob sends a message to Alice; the ciphertext is $C=(C_1,C_2)$. Bob randomly chooses $k\in F_p^*$:

    $C_1 \equiv g^k\pmod{p}$ $C_2\equiv y_A^k\cdot M$

    Alice decrypts: $M=\dfrac{C_2}{C_1^{x_A}}$.

    • Not resistant to CPA/CCA attacks? (In practice, resistant variants are used.)

Security Models for Public-Key Encryption

Chosen Plaintext Attack (CPA) Security Model
  1. C sends public key $p_k$ to A.
  2. A sends $m_0,m_1$ to C.
  3. C randomly encrypts one of $m_0,m_1$ and sends it to A; A must determine which message corresponds to the challenge ciphertext.
Chosen Ciphertext Attack (CCA) Security Model
  1. A has access to $Dec_{sk}()$.
  2. C sends public key $p_k$ to A.
  3. A sends $m_0,m_1$ to C.
  4. C randomly encrypts one of $m_0,m_1$ and sends it to A.
  5. A has access to $Dec_{sk}()$ (except for the challenge ciphertext) and must determine the message.

A decryption oracle is added, allowing immediate access to the plaintext for any ciphertext.

Elliptic Curves

$E_p(a,b)(x,y):y^2=x^3+ax+b$ with $4a^3+27b^2\ne 0$, plus the point at infinity.

It can be shown that $E(x, y)$ together with the defined addition forms an additive group.

Let $L$ be the line through $P$ and $Q$. $L$ intersects $E$ at a third point $R’$. $P+Q$ is defined as $R = -R’$. The geometric meaning is:

  • If $x_1 \ne x_2$, $P+Q=R$: the reflection across the x-axis of the intersection of the line through P and Q with E.
  • If $x_1=x_2$ and $y_1=-y_2$, $P+Q=O$: the point at infinity.
  • If $x_1=x_2$ and $y_1=y_2$, $P+Q=2P$: the reflection across the x-axis of the intersection of the tangent to E at P with E.

It is a cyclic Abelian group, so a discrete logarithm problem can be defined on it, and this problem is hard, so it can be used for encryption.

Similarly, DH and ElGamal can be defined (but over an additive group rather than a multiplicative group).

The explicit addition formula: $x_3=\lambda^2-x_1-x_2;y_3=\lambda(x_1-x_3)-y_1$.

SM2

Notation:

  • KDF(input): derive a random number of specified length from the input.
  • H(input): compute the hash function value of the input.
  • All exponentiation operations are performed on the elliptic curve group.

Computation:

  • Key generation
    • Choose private key $x$, compute public key $g^x$.
  • Encryption algorithm
    • Choose a random number $k$, compute $C_1=g^k$.
    • Compute $C_2= \text{KDF}((g^x)^k)\oplus M$.
    • Compute $C_3= \text H(C_2,M)$.
    • Ciphertext: $C=C1 | C2 | C3$.
  • Decryption algorithm
    • Compute $M=C_2\oplus \text{KDF}((C_1)^x)$.
    • Verify whether $C_3= \text H(C_2,M)$ holds.
    • If it holds, output $M$ as the decryption result.
    • Otherwise, report an error and exit.

Publicly Accessible Directory

Public-Key Authority

Identity Authentication Protocols

Password Authentication

Essentially entering a password.

  • Online dictionary attack: exhaustively try all possible passwords (starting from common ones).
  • Offline dictionary attack: obtain all $H(p_w)$, enumerate $p_w$.
  • Offline dictionary attack with preprocessing: precompute hash values for all possible passwords.

Increasing difficulty:

  • Add a public salt.
  • Add a secret salt.
  • Use a slow hash function.
  • Use a memory-hard hash function.

Kerberos

Introduce an authentication server and a ticket-granting server. The former only gives users tickets to access the ticket-granting server; the latter only gives users tickets to access other applications.
