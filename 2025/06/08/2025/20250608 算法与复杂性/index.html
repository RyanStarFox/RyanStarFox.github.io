符号

符号$O$：$f(n)=O(g(n))$，复杂性$f(n)\leq g(n)$，$\exists c,N, \forall n\geq N,g(n)\leq cf(n)\Rightarrow g(n)=O(f(n))$

符号$\Omega$：$f(n)=\Omega(g(n))$，复杂性$f(n)\geq g(n)$，$g(n)=O(f(n))\Rightarrow f(n)=\Omega(g(n))$

符号$\Theta$：$f(n)=\Theta(g(n))$，复杂性$f(n)=g(n)$，$f(n)=O(g(n))\wedge g(n)=O(f(n))\Rightarrow f(n)=\Theta(g(n))$

符号$o$：$f(n)=o(g(n))$，复杂性$f(n)< g(n)$，$\forall c,\exists N>0,s.t\ \forall n \geq N,f(n)\leq cg(n)\Rightarrow f(n)=o(g(n))$

分治问题

假设$a$个子问题，每个问题的规模是原始问题的$1/b$，组合各子问题的运行时间是$cn^k$，即

$T(n)=aT(n/b)+cn^k$

$T(n)=\begin{cases}O(n^{\log_ba})&a>b^k\O(n^k\log n)&a=b^k\O(n^k)&a<b^k\end{cases}$

Master Theorem

$T(n)=aT(n/c)+f(n)$

  1. if $f(n)=O(n^{\log_ca-\epsilon})$ for some $\epsilon>0$, then $T(n)=\Theta(n^{\log_ca})$
  2. if $f(n) = \Theta( n^{\log_ca} \cdot (\log n)^k ) $ for some$ k>=0$, then $T(n) = \Theta(n^{\log_ca} \cdot (\log n)^k )$
  3. If $f(n)=W(n^{\log_ca+\epsilon}) $ for some $e>0$ and if $a\cdot f(n/c)\leq kf(n) $ for some constant $ k<1$ and all sufficiently large $n$, then $T(n)=\Theta(f(n))$

注：以上三种情况不是完整覆盖所有情况

Divide and conquer problems

Assume there are $a$ subproblems, each of size $1/b$ of the original problem, and the time to combine subproblems is $cn^k$, i.e.

$T(n)=aT(n/b)+cn^k$

$T(n)=\begin{cases}O(n^{\log_ba})&a>b^k\O(n^k\log n)&a=b^k\O(n^k)&a<b^k\end{cases}$

Master Theorem

$T(n)=aT(n/c)+f(n)$

  1. if $f(n)=O(n^{\log_ca-\epsilon})$ for some $\epsilon>0$, then $T(n)=\Theta(n^{\log_ca})$
  2. if $f(n) = \Theta( n^{\log_ca} \cdot (\log n)^k ) $ for some$ k>=0$, then $T(n) = \Theta(n^{\log_ca} \cdot (\log n)^k )$
  3. If $f(n)=W(n^{\log_ca+\epsilon}) $ for some $e>0$ and if $a\cdot f(n/c)\leq kf(n) $ for some constant $ k<1$ and all sufficiently large $n$, then $T(n)=\Theta(f(n))$

Note: The above three cases do not completely cover all cases.

05 Induction-Based Algorithm Design

  1. Polynomial evaluation

    $p_n(x)=xp_{n-1}(x)+a_0$

  2. Find the largest induced subgraph where every vertex has degree > k

    Just delete vertices with degree less than k, update degrees; the deletion order does not matter.

  3. Find a subset with a one-to-one mapping

    Delete points that are not mapped to.

  4. Celebrity problem

    Don’t think from the person’s perspective, think from the question’s perspective. One question can determine that at least one person is not a celebrity; finally verify the remaining person to see if they are a celebrity.

  5. Outline problem

    Divide and conquer

  6. Find the maximum continuous subsequence

    Induction hypothesis: know how to find the maximum subsequence for size less than n, as well as the maximum subsequence ending as a suffix.

  7. Knapsack problem

    Dynamic programming

06 Algorithms for Sequences and Sets

Binary Search

  1. Basic binary search O(log n)

  2. Binary search on a cyclic sequence

    Find the minimum element in a cyclically increasing sequence.

    If we consider $x_p,x_q$, and if $x_p<x_q$, then the minimum element cannot be between $x_p$ and $x_q$.

  3. Binary search for $a_i=i$

    Examine the value of $a_{\frac n2}$ and decide whether to search in the front or the back.

  4. Overlapping subsequence problem

    If there is an upper bound, use binary search.

    If there is no upper bound, double $i$ until a suitable range is found.

  5. Solving equations

    Use continuity to repeatedly reduce the range where a solution exists.

  6. Interpolation search O(log log n), but not necessarily more efficient than binary search.

Finding the Majority Element

Here “majority” means: appears more than half the time.

  1. Brute force

  4. Advanced algorithm

    i X[i] C (candidate) M (counter) Operation description
    2 2 2 1 → 2 X[i] == C, M++
    3 1 2 2 → 1 X[i] ≠ C, M–
    4 1 2 1 → 0 X[i] ≠ C, M–
    5 1 1 0 → 1 M is 0, change candidate to X[i]=1, M=1
    6 2 1 1 → 0 X[i] ≠ C, M–
    7 2 2 0 → 1 M is 0, change candidate to X[i]=2, M=1

    After finding the candidate, verify it.

  5. Frequent elements

    Find the t most frequent elements.

    Only an approximate algorithm exists: specify k counters.

    1. If there is a corresponding counter, increment that counter by 1.
    2. If there is no corresponding counter and the number of existing counters is less than k, allocate a new counter for this data item with value 1.
    3. If there is no corresponding counter and there are already k counters, decrement all counter values by 1, remove counters with value 0, and discard the new data item.

07 Graph Algorithms

DFS

Four types of edges in DFS:

  1. Tree edge: edge that first visits a new node and adds it to the DFS tree.
  2. Back edge: visits an ancestor node that has not finished and is still in recursion.
  3. Forward edge: visits a descendant node that has already finished.
  4. Cross edge: visits a node that has already finished, but is neither an ancestor nor a descendant.

A directed graph has a directed cycle $\Leftrightarrow$ G has a back edge.

Topological Sort

Find vertices with indegree 0, mark as visited, and update the adjacency list.

Single-Source Shortest Paths

In an acyclic directed graph, the shortest paths from v to all other vertices in G.

Using topological sort (only graphs that can be topologically sorted can use this method)

Assume v has label k; vertices with labels less than k need not be considered, since there is no path; for labels greater than k, use induction: $min(l_i)+1$ for $i$ in $curr.parents$.

General approach: Dijkstra’s algorithm

Use a priority queue to decide which vertex to update next.

All-pairs shortest paths: Floyd’s algorithm

Edge weights can be negative, but there cannot be negative-weight cycles.

Uses three nested loops.

Initialize distances between connected vertices as the edge length, and others as +inf.

Check whether each vertex can serve as an intermediate node for two other vertices; if so, update the shortest path.

Can detect negative cycles (if running it twice produces changes, there is a negative cycle).

Transitive closure: Floyd-Warshall algorithm

Minimum Cost Spanning Tree

Kruskal/Prim algorithm.

The former expands edges + uses disjoint set union; the latter expands vertices + uses greedy method.

Partition Biconnected Components: Tarjan’s Method

Articulation point (cut vertex): a node whose removal can separate the graph.

A biconnected component is a component with no articulation point. A vertex can belong to different biconnected components, but an edge cannot.

To find all articulation points:

Use one DFS, updating timestamps and low values.

Partition Strongly Connected Components: Tarjan’s Method

Can use a method similar to the biconnected component partition; the criterion changes from dfn >= to dfn ==.

Matching

A matching is a set of edges with no common vertices between any two edges.

  • Perfect matching: a matching in which all vertices are matched.
  • Maximum matching: a matching with the maximum number of edges.
  • Maximal matching: a matching to which no additional edge can be added.

A maximal matching is not necessarily a maximum matching.

  1. Perfect matching in very dense graphs.
  2. Bipartite matching.

Both are achieved by exchanging (augmenting paths).

08 Geometric Algorithms

Determine Whether a Point Is Inside a Polygon

A line from any external point to this point has an odd number of intersections with the polygon.

There are special cases.

Construct a Simple Polygon

  1. Consider a large circle C containing all points; start rotating from the circle center (special cases exist).
  2. Start scanning from the point with maximum x-coordinate and minimum y-coordinate (special cases also exist).

Convex Hull

Direct method: extension + recursion O(n^2)

Know how to find the convex hull of <n points, then try to find the convex hull including the n-th point.

Improvement: when adding a new point, delete points inside the old hull, connect the new point to points on the old hull to find supporting lines, and thus find two points to connect with the new point, forming a new hull.

Gift Wrapping O(n^2)

Start from an extreme point and find supporting lines; instead of constructing the convex hull incrementally, directly find parts of the convex hull.

Graham scan algorithm O(n log n)

Similar to gift wrapping, but does not directly find a part of the hull. First fix an extreme point $p_1$ on the x-axis, then compute the angle between $p_i p_1$ and the x-axis, sort in increasing order, and then add points one by one to the convex hull.

Closest Pair of Points

Direct method O(n^2)

Directly compute distances between points and find the minimum.

Divide and conquer O(n log^2 n) -> O(n log n)

If there are only two points, take their distance directly.

Otherwise, divide into two groups, find the minimum in each, and find the minimum of cross terms.

For cross terms, only consider a strip of width twice the minimum.

If the y-coordinate ordering is preserved during each merge, the complexity can be reduced to $O(n\log n)$.

Finding Intersections

Intersections of horizontal and vertical line segments

Direct method $O(mn)$

Sweep line technique $O((m+n)\log(m+n)+R)$

Intersections of line segments

Sweep line technique $O((2n+m)\log(2n+m))$

The sweep state set is dynamic geometry, describing the current sweep line state. It changes in the following situations:

  1. Encountering a new segment.
  2. An existing segment ends.
  3. Intersection of two segments.

Art Gallery Problem

Polygon Triangulation

If it is a monotone polygon

Sweep line algorithm for triangulation.

If it is a general polygon

Add diagonals to remove turning points.

For split, merge, and start, there are different handling methods.

Intersecting Half-Planes Problem

Divide and conquer $O(n\log n)$

Intersection of Two Convex Polygons

Sweep line algorithm; the sweep line only needs to remember 4 edges, $O(n)$.

Voronoi Diagram

Use Fortune’s algorithm, a sweep line algorithm. It specifies both a sweep line and a coastline (a series of parabolas; above the coastline, things do not change).

  1. Site event: When the sweep line passes through a site, a site event is generated. Insert a new parabola.
  2. When the left and right parabolas meet, the middle parabola disappears, forming a new Voronoi vertex.

09 Algebraic and Numerical Algorithms

Sources of Error

  1. Truncation error: error caused by truncating a Taylor series.
  2. Large number swallows small number: 2^100^+1-2^100^=0
  3. Stability: Recurrent algorithms accumulate errors.

Power Computation

  1. Direct induction: $n^k = n \cdot n^{k-1}, O(k)$
  2. Binary induction: $n^k = (n^{\frac{k}{2}})^2, O(\log k)$

Greatest Common Divisor

Euclidean algorithm.

Least common multiple can be obtained from the greatest common divisor.

Polynomial Multiplication

Divide and conquer; also, 4 multiplications can be optimized to 3 because B+C = E - A - D.

Positive Integer Multiplication

For n-digit numbers, $O(n^2)$.

Use a divide-and-conquer method similar to polynomial multiplication.

Matrix Multiplication

Also similar divide-and-conquer $O(n^3)$; can also use Strassen’s algorithm for similar optimization, $O(n^{2.81})$.

Boolean Matrix Multiplication

Cannot be optimized by Strassen’s algorithm because subtraction is not defined for Boolean operations.

Method 1

Precompute all possible k-dimensional Boolean inner products, then look them up, $O(n^3/\log n)$.

Method 2

Decompose into sum of products of columns of A and rows of B + lookup, $O(n^3/\log n)$.

Method 3

Build an n-dimensional vector addition table, then partition, $O(n^3/\log^2 n)$.

Matrix Chain Multiplication

Linear programming.

Multiplying an mn matrix and an nk matrix has default time complexity $O(mnk)$.

Polynomial Multiplication 2

Represent a polynomial function using points on the function, first perform forward Fourier transform, then inverse Fourier transform.

Forward Fourier transform

Among the chosen points, there are opposite numbers, reducing computation by half, then compute inductively (requires introducing complex numbers).

Inverse Fourier transform

Find the inverse of the matrix, which is $[V(\omega)]^{-1}=\dfrac{1}{n} V(\dfrac{1}{\omega})$.

Nonlinear Methods for Solving Equations

Bisection Method

Disadvantage: cannot guarantee the precision of x; possibly y differs very little but x differs a lot.

Iterative Method for Roots

It is the cobweb method mentioned by Dong; the question is whether it converges.

Newton’s Method

Find the next approximation using the tangent line; performance depends on the choice of x.

11 Computers Are Not All-Powerful

NPC Problems from Class

  • Vertex cover problem

    Let G=(V,E) be an undirected graph. A vertex cover of G is a set of vertices such that every edge in G is incident to at least one vertex in the set.

    Problem: Given an undirected graph G=(V,E) and an integer k, determine whether G has a vertex cover with at most k vertices.

  • Dominating set problem

    Let G=(V,E) be an undirected graph. If a vertex set D satisfies that every vertex in G is either in D or adjacent to at least one vertex in D, then D is called a dominating set.

    Problem: Given an undirected graph G=(V,E) and an integer k, determine whether G has a dominating set with at most k vertices.

  • 3SAT problem

    The 3SAT problem is a restricted version of the general SAT problem. An instance of 3SAT is a Boolean expression in which each clause contains exactly 3 variables.

    Problem: Given a Boolean expression in CNF form with exactly 3 variables per clause, determine whether it is satisfiable.

  • Clique problem

    Given an undirected graph G=(V,E), a clique C in G is a subgraph of G such that every two vertices in C are adjacent; in other words, a clique is a complete subgraph.

    Problem: Given an undirected graph G=(V,E) and an integer k, determine whether G contains a clique of size at least k.

  • 3-coloring problem

    Let G=(V,E) be an undirected graph. A proper coloring of G is an assignment of colors to all vertices such that each vertex is assigned one color and adjacent vertices are not assigned the same color.

    Problem: Given an undirected graph G=(V,E), determine whether G can be colored with 3 colors.
