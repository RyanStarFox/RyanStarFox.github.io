vector

构造函数和析构函数

  • vector(size_type n, const value_type& val)：构造一个包含n个元素的vector，每个元素都初始化为val。
  • vector(const vector& x)：复制构造函数，创建一个与x相同的vector。

容量相关函数

  • size()：返回vector中元素的个数。
  • empty()：检查vector是否为空，如果为空则返回true。

元素访问函数

  • operator[]：返回指定位置元素的引用。
  • at(size_type n)：返回指定位置元素的引用，同时进行边界检查。
  • front()：返回vector中第一个元素的引用。
  • back()：返回vector中最后一个元素的引用。

修改器函数

  • assign(size_type n, const value_type& val)：将vector中的元素替换为n个val。
  • push_back(const value_type& val)：在vector的末尾添加一个元素val。
  • pop_back()：删除vector末尾的元素。
  • insert(iterator position, const value_type& val)：在position位置插入一个元素val。
  • erase(iterator position)：删除position位置处的元素。
  • erase(iterator first, iterator last)：删除[first, last)区间内的元素。
  • clear()：清空vector中的所有元素。

迭代器函数

  • begin()：返回指向vector中第一个元素的迭代器。

  • end()：返回指向vector中最后一个元素之后位置的迭代器。

  • rbegin()：返回指向vector中最后一个元素的逆向迭代器。

  • rend()：返回指向vector中第一个元素之前位置的逆向迭代器。

  • vector::iterator&vector::reverse_iterator

  • 迭代器可以用类似这样的语法：

    或者

队列操作

  • emplace(iterator position, const value_type& val)：在vector的指定位置直接构造元素（是插入）。
  • emplace_back(val)：在vector的末尾直接构造元素。

其他操作

  • swap(vector<T>& other)：交换两个 vector的内容。
  • assign(size_type n, const T& val)：将 vector中的元素替换为 n个 val。
  • assign(iterator first, iterator last)：将 vector中的元素替换为指定范围的元素。

pair

构造函数

  • pair(const first_type& a, const second_type& b)：创建一个pair，其first成员初始化为a，second成员初始化为b。

成员访问

  • first：返回pair的第一个成员的引用。
  • second：返回pair的第二个成员的引用。

成员函数

  • swap(pair& p)：交换两个pair的成员。

非成员函数

  • make_pair(T1 a, T2 b)：创建一个pair对象，其first成员用a初始化，second成员用b初始化。
  • pair的比较规则：先比较pair.first，再比较pair.second

deque

同 vector

stack

构造函数

  • stack<T> stk;：创建一个空的 stack，元素类型为 T。
  • stack<T> stk(c);：使用容器 c 的副本作为 stack 的底层容器来创建 stack。
  • stack<T, Container<T>> stk;：创建一个 stack，元素类型为 T，底层容器为 Container。

容量操作

  • empty()：检查 stack 是否为空。
  • size()：返回 stack 中元素的数量。

元素访问

  • top()：返回栈顶元素的引用。如果栈为空，则行为未定义。

修改器

  • push(const T& val)：将元素 val 压入栈顶。
  • pop()：移除栈顶元素。如果栈为空，则行为未定义。
  • emplace(args...)：在栈顶构造元素，使用 args 作为构造函数的参数。
  • swap(stack<T>& other)：交换两个 stack 的内容。

queue

同 stack，元素访问变成 front()和 back()

priority_queue

同 queue

set

创建 set

  • set<T> s;：创建一个空的 set，元素类型为 T，默认使用 operator< 作为比较函数。
  • set<T, Compare> s;：创建一个 set，元素类型为 T，比较函数为 Compare。
  • 可以直接用 {}来初始化

容量操作

  • empty()：检查 set 是否为空。
  • size()：返回 set 中元素的数量。

元素访问

  • find(const T& val)：返回一个指向 set 中值为 val 的元素的迭代器，如果找不到，则返回 end()。
  • count(const T& val)：返回 set 中值为 val 的元素的数量，由于 set 中元素唯一，因此结果只能是 0 或 1。

修改器

  • insert(const T& val)：将 val 插入到 set 中，如果 val 已经存在，则 set 不变。
  • erase(iterator position)：从 set 中删除迭代器 position 指向的元素。
  • erase(const T& val)：从 set 中删除所有值为 val 的元素。
  • clear()：删除 set 中所有的元素。
  • emplace(args...)：在 set 中构造元素，使用 args 作为构造函数的参数。
  • emplace_hint(const_iterator position, args...)：在 set 中构造元素，使用 args 作为构造函数的参数，并尽量在 position 之前插入。

map

创建 map

  • map<Key, T> m;：创建一个空的 map，键类型为 Key，值类型为 T，默认使用 operator< 作为比较函数。
  • map<Key, T, Compare> m;：创建一个 map，键类型为 Key，值类型为 T，比较函数为 Compare。

容量操作

  • empty()：检查 map 是否为空。
  • size()：返回 map 中键值对的数量。

元素访问

  • operator[]：允许通过键直接访问对应的值，如果键不存在，则自动创建一个键值对，其值为值类型的默认构造值。
  • at(const Key& key)：返回键 key 对应的值，如果键不存在，则抛出 std::out_of_range 异常。

查找元素

  • find(const Key& key)：返回一个指向键 key 对应的键值对的迭代器，如果找不到，则返回 end()。
  • count(const Key& key)：返回 map 中键 key 的数量，由于键是唯一的，结果只能是 0 或 1。

修改器

  • insert(const value_type& val)：插入一个键值对。
  • erase(iterator position)：删除迭代器 position 指向的键值对。
  • erase(const Key& key)：删除键 key 对应的键值对。
  • clear()：删除 map 中所有的键值对。
  • emplace(args...)：在 map 中构造键值对，使用 args 作为构造函数的参数。

string

字符串长度和容量

  • size()：返回字符串中的字符数。

字符串修改

  • clear()：清空字符串。
  • insert(size_t pos, const string& str)：在位置 pos 插入字符串 str。
  • erase(size_t pos, size_t len)：删除从位置 pos 开始的 len 个字符。
  • replace(size_t pos, size_t len, const string& str)：将位置 pos 开始的 len 个字符替换为字符串 str。
  • push_back(char c)：在字符串末尾添加字符 c。
  • pop_back()：删除字符串末尾的字符。

字符串查询

  • find(const string& str, size_t pos=0)：从位置 pos 开始查找子字符串 str，返回找到的位置，如果没有找到则返回 string::npos。
  • rfind(const string& str, size_t pos=npos)：从位置 pos 开始向左查找子字符串 str，返回找到的位置，如果没有找到则返回 string::npos。
  • find_first_of(const string& str, size_t pos=0)：从位置 pos 开始查找任意一个属于 str 的字符，返回找到的位置，如果没有找到则返回 string::npos。

字符串的子串

  • substr(size_t pos, size_t len)：返回从位置 pos 开始的 len 个字符的子字符串。

字符串的连接

  • operator+(const string& str)：返回两个字符串连接后的新字符串。
  • append(const string& str)：将字符串 str 添加到当前字符串的末尾。

字符串与数字之间的转换

  • to_string
  • stoi
  • stod

iostream

  1. Control precision

    cout << setprecision(3) << 3.1415926

  2. Decimal mode: fixed

  3. Scientific notation: scientific

fstream

  1. Read file content line by line

    #include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ifstream file("example.txt");  // Open the file

    if (!file) {  // Check if the file was opened successfully
        std::cerr << "Unable to open the file!" << std::endl;
        return 1;
    }

    std::string line;
    // Read file content line by line
    while (std::getline(file, line)) {
        std::cout << line << std::endl;  // Output each line
    }

    file.close();  // Close the file
    return 0;
}

  2. Write to a file

    std::ofstream file("output.txt");
file << "Hello, World!" << std::endl;

sstream

  1. istream

    # include <iostream>
# include <sstream>
using namespace std;

int main(){
    std::istringstream iss("42 3.14 hello");
    int i;
    double d;
    std::string str;
    iss >> i >> d >> str;
    std::cout << i << ", " << d << ", " << str << std::endl;
}

  2. ostream

    std::ostringstream oss;
oss << 42 << " " << 3.14 << " " << "hello";
std::string result = oss.str();  // Get the output string
std::cout << result << std::endl;  // Output: "42 3.14 hello"

}

ss = stringstream(input2);

vector

Constructors and destructors

  • vector(size_type n, const value_type& val): Construct a vector containing n elements, each initialized to val.
  • vector(const vector& x): Copy constructor, creates a vector identical to x.

Capacity-related functions

  • size(): Return the number of elements in the vector.
  • empty(): Check if the vector is empty; returns true if it is.

Element access functions

  • operator[]: Return a reference to the element at the specified position.
  • at(size_type n): Return a reference to the element at the specified position, with boundary checking.
  • front(): Return a reference to the first element in the vector.
  • back(): Return a reference to the last element in the vector.

Modifier functions

  • assign(size_type n, const value_type& val): Replace the elements in the vector with n copies of val.
  • push_back(const value_type& val): Add an element val to the end of the vector.
  • pop_back(): Remove the last element of the vector.
  • insert(iterator position, const value_type& val): Insert an element val at the position specified by position.
  • erase(iterator position): Delete the element at the position specified by position.
  • erase(iterator first, iterator last): Delete the elements in the range [first, last).
  • clear(): Remove all elements from the vector.

Iterator functions

  • begin(): Return an iterator pointing to the first element in the vector.

  • end(): Return an iterator pointing to the position after the last element in the vector.

  • rbegin(): Return a reverse iterator pointing to the last element in the vector.

  • rend(): Return a reverse iterator pointing to the position before the first element in the vector.

  • vector::iterator & vector::reverse_iterator

  • Iterators can be used with syntax like this:

    for (auto i:v){ cout << i << " ";}

    or

    for (auto i = v.begin(); i!=v.end; i++){cout << *i << " "}

Queue operations

  • emplace(iterator position, const value_type& val): Construct an element directly at the specified position in the vector (this is an insertion operation).
  • emplace_back(val): Construct an element directly at the end of the vector.

Other operations

  • swap(vector<T>& other): Swap the contents of two vectors.
  • assign(size_type n, const T& val): Replace the elements of the vector with n copies of val.
  • assign(iterator first, iterator last): Replace the elements of the vector with the elements in the specified range.

pair

Constructor

  • pair(const first_type& a, const second_type& b): Create a pair where the first member is initialized to a and the second member is initialized to b.

Member access

  • first: Return a reference to the first member of the pair.
  • second: Return a reference to the second member of the pair.

Member functions

  • swap(pair& p): Swap the members of two pairs.

Non-member functions

  • make_pair(T1 a, T2 b): Create a pair object where the first member is initialized to a and the second member is initialized to b.
  • Comparison rule for pairs: First compare pair.first, then compare pair.second.

deque

Same as vector.

stack

Constructors

  • stack<T> stk;: Create an empty stack with element type T.
  • stack<T> stk(c);: Create a stack using a copy of container c as its underlying container.
  • stack<T, Container<T>> stk;: Create a stack with element type T and underlying container Container.

Capacity operations

  • empty(): Check if the stack is empty.
  • size(): Return the number of elements in the stack.

Element access

  • top(): Return a reference to the top element of the stack. The behavior is undefined if the stack is empty.

Modifiers

  • push(const T& val): Push element val onto the top of the stack.
  • pop(): Remove the top element of the stack. The behavior is undefined if the stack is empty.
  • emplace(args...): Construct an element at the top of the stack using args as constructor arguments.
  • swap(stack<T>& other): Swap the contents of two stacks.

queue

Same as stack, but element access becomes front() and back().

priority_queue

Same as queue.

set

Creating a set

  • set<T> s;: Create an empty set with element type T, using operator< as the default comparison function.
  • set<T, Compare> s;: Create a set with element type T and comparison function Compare.
  • You can also initialize it directly with {}.

Capacity operations

  • empty(): Check if the set is empty.
  • size(): Return the number of elements in the set.

Element access

  • find(const T& val): Return an iterator pointing to the element with value val in the set; if not found, return end().
  • count(const T& val): Return the number of elements with value val in the set. Since elements in a set are unique, the result can only be 0 or 1.

Modifiers

  • insert(const T& val): Insert val into the set; if val already exists, the set remains unchanged.
  • erase(iterator position): Delete the element pointed to by the iterator position from the set.
  • erase(const T& val): Delete all elements with value val from the set.
  • clear(): Delete all elements from the set.
  • emplace(args...): Construct an element in the set using args as constructor arguments.
  • emplace_hint(const_iterator position, args...): Construct an element in the set using args as constructor arguments, and try to insert it before position.

map

Creating a map

  • map<Key, T> m;: Create an empty map with key type Key and value type T, using operator< as the default comparison function.
  • map<Key, T, Compare> m;: Create a map with key type Key and value type T, and comparison function Compare.

Capacity operations

  • empty(): Check if the map is empty.
  • size(): Return the number of key-value pairs in the map.

Element access

  • operator[]: Allow direct access to the corresponding value via the key; if the key does not exist, a new key-value pair is automatically created with the value initialized to the default value of its type.
  • at(const Key& key): Return the value corresponding to key; if the key does not exist, throw a std::out_of_range exception.

Finding elements

  • find(const Key& key): Return an iterator pointing to the key-value pair corresponding to key; if not found, return end().
  • count(const Key& key): Return the number of keys with value key in the map. Since keys are unique, the result can only be 0 or 1.

Modifiers

  • insert(const value_type& val): Insert a key-value pair into the map.
  • erase(iterator position): Delete the key-value pair pointed to by the iterator position.
  • erase(const Key& key): Delete the key-value pair corresponding to key from the map.
  • clear(): Delete all key-value pairs from the map.
  • emplace(args...): Construct a key-value pair in the map using args as constructor arguments.

string

String length and capacity

  • size(): Return the number of characters in the string.

String modification

  • clear(): Empty the string.
  • insert(size_t pos, const string& str): Insert string str at position pos.
  • erase(size_t pos, size_t len): Delete len characters starting from position pos.
  • replace(size_t pos, size_t len, const string& str): Replace len characters starting from position pos with string str.
  • push_back(char c): Add character c to the end of the string.
  • pop_back(): Delete the last character of the string.

String querying

  • find(const string& str, size_t pos=0): Search for substring str starting from position pos; return the found position, or string::npos if not found.
  • rfind(const string& str, size_t pos=npos): Search for substring str moving backward from position pos; return the found position, or string::npos if not found.
  • find_first_of(const string& str, size_t pos=0): Search for any character that belongs to str starting from position pos; return the found position, or string::npos if not found.

String substrings

  • substr(size_t pos, size_t len): Return a substring consisting of len characters starting from position pos.

String concatenation

  • operator+(const string& str): Return a new string formed by concatenating the current string with str.
  • append(const string& str): Append string str to the end of the current string.

Conversion between strings and numbers

  • to_string
  • stoi
  • stod

Operator overloading

#include <iostream>
using namespace std;

class Complex {
public:
    double real, imag;

    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    Complex operator+(const Complex& other) {
        return Complex(real + other.real, imag + other.imag);
    }

    void display() const {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex c1(1.0, 2.0), c2(3.0, 4.0);
    Complex c3 = c1 + c2;
    c3.display();  // Output: 4.0 + 6.0i
    return 0;
}
