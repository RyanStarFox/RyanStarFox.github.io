图论整理

第一章 基本概念

1.1 图的概念

  1. $(V(G),E(G))$称为图，$V(G)$是非空集合，称为顶点集，$E(G)$是$V(G)$诸顶点之间边的集合。常用$G=(V,E)$表示图

  2. 只讨论有限图，$|V|=n$称为图的阶，$|E|=m$

  3. 一些概念：

    1. $e_k=(v_i,v_j)$

      1. 称$v_i与v_j是相邻顶点；e_k分别与v_i,v_j关联$
      2. 称$v_i是e_k的始点，v_j是e_k的终点，v_i是v_j的直接前趋，v_j是v_i的直接后继$

    2. 邻接边：有一个共同顶点的两条边

    3. 有向图：全部由有向边构成的图

      **无向图：**全部由无向边构成的图

      **混合图：**既有有向边又有无向边构成的图

    4. **自环：**只与一个顶点关联的边

    5. **多重边：**同一对顶点之间存在多条边

      **多重图：**含有重边的图

    6. **孤立点：**没有与任何边关联的顶点

    7. **度$d(v)$：**与顶点关联的边的数目

      **入读：**入边条数

      **出度：**出边条数

      **奇点：**度为奇数的点

      **偶点：**度为偶数的点

    8. **简单图：**不存在自环的无向图

  4. $\sum\limits_{v\in{V(G)}}d(v)=2m$

  5. G中奇数的顶点必为偶数个

  6. G中出度之和=入度之和

  7. Kn的变数是$\cfrac12n(n-1)$

  8. 非空简单图G中一定存在度相同的顶点

  9. n阶完全图：Kn

  10. 完全二分图：Km,n

  11. **平凡图：**n=1的图

  12. **空图/零图：**m=0的图

  13. **（k度）正则图：**所有顶点度数均相等（为k）的图

  14. 阶为k的(k-1)-正则图：k-完全图

  15. **正权图：**权为正实数的赋权图

  16. 子图：$V’\in V,E’\in E$

    支撑子图/生成子图：$V’=V,E’\in E$

    导出子图：$V’\in V,E’_V = E_V$

  17. 邻点集：$\Gamma(v)$

    直接后继集/外邻集：$\Gamma^+(v)$

    直接前趋集/内邻集：$\Gamma^-(v)$

1.2 图的代数表示

  1. 邻接矩阵
    • 对称矩阵
    • 可以表示自环
    • 无法表示重边
  2. 权矩阵
    • 邻接矩阵基础上加入权值信息
  3. 关联矩阵
    • n x m的矩阵
    • $b_{ij}=\begin{cases}1,&e_j=(v_i,v_k)\in E\-1,&e_j=(v_k,v_i)\in E\0,&其他\end{cases}$
    • 无法表示自环
    • 可以表示重边
  4. 边列表
    • 边列表是对关联矩阵的列进行压缩的结果
    • 两个m维向量$\vec A$和$\vec B$，前者存放起点，后者存放终点
    • 可选的$\vec Z$，存放权值
    • 可以表示自环
    • 可以表示重边
  5. 正向表
    • 对邻接矩阵的行进行压缩的结果，把每个顶点的直接后趋集中在一起存放
      • n+1维向量$\vec A$，m维向量$\vec B$
      • $d^+(v_i)=A(i+1)-A(i)$
      • $B(A(i))$到$B(A(i+1)-1)中的任一个值，都是v_i的直接后继$
    • 可选的$\vec Z$，存放权值
    • 可以表示自环
    • 可以表示重边
  6. 逆向表
    • 与正向表类似，把每个顶点的直接前趋放在一张表里存放
  7. 邻接表
    • 每一个表顶点|a|b|c|，a存放点编号，b存放边的数值，c存放下一表顶点的地址指针
    • 可以存放权值
    • 可以表示自环
    • 可以表示重边

第二章 道路和回路

2.1 图的连通性

  1. 有向图中：

    有向道路、有向回路：字面意思

    无重边：简单有向道路/简单有向回路

    无重边、无重顶点：初级有向道路/初级有向回路，简称路和回路

  2. 无向图中：

    道路/链、回路/圈：字面意思

    无重边：简单道路/简单回路

    无重边、无重顶点：初级道路/初级回路

**弦：**圈中不相邻顶点的边

**连通图：**G的任意两点之间都存在道路H不是G任何连通子图的真子图

**树：**不含回路的连通图

**割边/割点：**移去后使得原有图不再连通的边/顶点

**块：**G中极大的没有割点的连通子图

割点相关等价命题：

  1. v是G的一个割点
  2. 存在与v不同的点u,w，使得任何一条u到w的道路Puw经过v
  3. V-v可以划分为两个顶点集U，W，任意$u\in U,w\in W$，u在每一条道路Puw上

割边相关等价命题：

  1. e是G的一条割边
  2. e不属于G的任何回路
  3. 存在G得顶点u，w，e属于u和w的任何一条道路Puw
  4. G-e可以划分为两个顶点集U和W，使得对任何顶点$u\in U,w\in W$，在G中的道路Puw都经过e

图G移去若干顶点后分为两个连通子图或者剩下一个孤立的点，这些点的集合称为点断集/断集A

$\mathcal K(G)=\min\limits_{A\in\emptyset}{|A|}$为断量

同理边断集B，边断量$\lambda(G)$

若$\mathcal K(G)\geq k$称G为k连通图，同理k边连通图

$\mathcal K(G)\leq \lambda(G)\leq \delta(G),\delta(G)是顶点的最小度$

2.3 欧拉道路与回路

**欧拉回路/道路：**经过所有边的简单回路/道路

**欧拉图：**存在欧拉回路

**半欧拉图：**存在欧拉道路而不存在欧拉回路

$存在欧拉回路\Leftrightarrow 各顶点的度为偶数/出度入读相等$

$存在欧拉道路\Leftrightarrow 只有两个度为奇数的点$

2.4 哈密顿道路与回路

**哈密顿回路/道路：**无向图的一条过全部顶点的初级回路

**哈密顿图：**含有H回路的无向连通图

**半哈密顿图：**含有H道路而不含H回路的无向连通图

一些充分定理：

  1. $\forall v_i,v_j，恒有d(v_i)+d(v_j)\geq n-1，则G中存在哈密顿道路$

  2. $\forall v_i,v_j，恒有d(v_i)+d(v_j)\geq n，则G中存在哈密顿回路$

  3. $若简单图每个顶点的度均大于等于\cfrac n2，则G有H回路$

  4. $设G是简单图，v_i,v_j是不相邻顶点，且满足d(v_i)+d(v_j)\geq n，则G存在H回路的充要条件是G+(v_i,v_j)有H回路$

  5. $先定义闭合图:若d(v_i)+d(v_j)\geq n，令G’=G+(v_i,v_j)，重复，直到不存在这样的顶点对为止，得到的即为闭合图，记作C(G)$

    $简单图G存在哈密顿回路的充要条件是其闭合图存在哈密顿回路$

  6. $若C(G)是完全图，则G有H回路$

2.6 最短路径：Dijkstra算法

2.7 关键路径：AOE

2.8 中国邮路

先找到奇点，选择最小的几条路径，加上使这些奇点变偶，然后欧拉回路

第三章 树

3.1 树的相关定义

不含任何回路的连通图称为树（T），T中的边称为树枝，度为1的顶点称为树叶

若T是G的支撑子图，且又是一棵树，则T使G的支撑树/生成树，又称G的树

3.5 Huffman树

小在左，大在右，0在左，1在右

3.6 最短树

  1. Kruskal算法：不断加入最短边，如成环则换次短边
  2. Prim算法：选到已选区域最近的点

第四章 平面图与图图的着色

4.1 平面图

平面图：能放在一个平面上，任何两条边都不相交，称G可嵌入平面，G是可平面图，其中一个嵌入称为平面图

G同构于平面图P，称P是G的一个平面嵌入

面/域：不含任何顶点和边的区域，其中诸边称为边界

欧拉公式：对于平面连通图，$d=m-n+2$

若G有k个连通支，则$n-m+d = k+1$

对于一般平面图G，恒有$n-m+d\geq 2$

若平面连通图G没有割边，且每个域的边界数至少t，则$m\leq\cfrac{t(n-2)}{t-2}$

4.2 极大平面图

极大平面图：

  1. 连通
  2. 不存在割边
  3. 每个域边界数为3
  4. 3d=2m, m=3n-6, d=2n-4

简单平面图满足$m\leq 3n-6,d\leq 2n-4$

简单平面图G中存在度小于6的顶点

4.3 非平面图

  1. K5是非平面图，也称K^(1)^
  2. K3,3是非平面图，也称K^(2)^
  3. K^(1)^和K^(2)^图上任意加一些度为2的顶点之后得到的图称为K^(1)^型图和K^(2)^型图，统称为K型图
  4. G是可平面图的充要条件是G不存在K型子图

4.4 对偶图

  1. 域->顶点，共边->相邻，求对呕吐的过程称为D过程（draw）
  2. 性质
    1. 若G是平面图，则G一定有唯一对偶图G^*^
    2. G^*^是连通图
    3. 若G是平面连通图，则（G^^)^^=G
    4. m=m^^, n=d^^, d=n^*^
    5. 若C是平面图G得一个初级回路，S^^是G^^中与C的各边ei对应的ei^^的集合，那么S^^是G^*^的一个割集
    6. G有对偶图等价于G为平面图
  3. 每一个平面图都是5-可着色的
  4. 如果平面图G有哈密顿回路，则四色猜想成立
  5. 若任何一个3-正则平面图的域4-可着色，则任何平面图的域4-可着色

4.5 色数与色数多项式

不断分割即可

Graph Theory Summary

Chapter 1: Basic Concepts

1.1 Concepts of Graphs

  1. $(V(G), E(G))$ is called a graph. $V(G)$ is a non-empty set called the vertex set, and $E(G)$ is the set of edges between vertices in $V(G)$. A graph is commonly denoted as $G=(V,E)$.

  2. We only discuss finite graphs here. $|V|=n$ is called the order of the graph, and $|E|=m$.

  3. Some concepts:

    1. $e_k=(v_i,v_j)$

      1. $v_i$ and $v_j$ are called adjacent vertices; $e_k$ is incident to both $v_i$ and $v_j$.
      2. $v_i$ is the start vertex of $e_k$, and $v_j$ is the end vertex of $e_k$. $v_i$ is the immediate predecessor of $v_j$, and $v_j$ is the immediate successor of $v_i$.

    2. Adjacent edges: Two edges that share a common vertex.

    3. Directed graph: A graph composed entirely of directed edges.

      Undirected graph: A graph composed entirely of undirected edges.

      Mixed graph: A graph containing both directed and undirected edges.

    4. Loop: An edge that is incident to only one vertex.

    5. Multiple edges: Multiple edges exist between the same pair of vertices.

      Multigraph: A graph containing multiple edges.

    6. Isolated vertex: A vertex that has no incident edges.

    7. Degree $d(v)$: The number of edges incident to a vertex.

      In-degree: The number of incoming edges.

      Out-degree: The number of outgoing edges.

      Odd vertex: A vertex with an odd degree.

      Even vertex: A vertex with an even degree.

    8. Simple graph: An undirected graph without loops.

  4. $\sum\limits_{v\in{V(G)}}d(v)=2m$.

  5. The number of odd-degree vertices in $G$ must be even.

  6. The sum of out-degrees in $G$ equals the sum of in-degrees.

  7. The number of edges in $K_n$ is $\cfrac12n(n-1)$.

  8. In any non-empty simple graph $G$, there must exist vertices with the same degree.

  9. Complete graph of order $n$: $K_n$.

  10. Complete bipartite graph: $K_{m,n}$.

  11. Trivial graph: A graph with $n=1$.

  12. Empty graph/null graph: A graph with $m=0$.

  13. $(k)$-regular graph: A graph where all vertices have equal degree (equal to $k$).

  14. A $(k-1)$-regular graph of order $k$ is a complete graph of order $k$.

  15. Weighted graph with positive weights: A weighted graph where all edge weights are positive real numbers.

  16. Subgraph: $V’\in V, E’\in E$.

    Spanning subgraph/generator subgraph: $V’=V, E’\in E$.

    Induced subgraph: $V’\in V, E’_V = E_V$.

  17. Neighbor set: $\Gamma(v)$.

    Set of immediate successors/external neighbor set: $\Gamma^+(v)$.

    Set of immediate predecessors/internal neighbor set: $\Gamma^-(v)$.

1.2 Algebraic Representations of Graphs

  1. Adjacency matrix
    • It is a symmetric matrix.
    • It can represent loops.
    • It cannot represent multiple edges.
  2. Weight matrix
    • It adds weight information to the adjacency matrix.
  3. Incidence matrix
    • It is an $n \times m$ matrix.
    • $b_{ij}=\begin{cases}1,&e_j=(v_i,v_k)\in E\-1,&e_j=(v_k,v_i)\in E\0,&otherwise\end{cases}$.
    • It cannot represent loops.
    • It can represent multiple edges.
  4. Edge list
    • The edge list is a compressed version of the columns of the incidence matrix.
    • There are two $m$-dimensional vectors $\vec A$ and $\vec B$; the former stores start vertices, and the latter stores end vertices.
    • An optional vector $\vec Z$ stores edge weights.
    • It can represent loops.
    • It can represent multiple edges.
  5. Forward star
    • It is a compressed version of the rows of the adjacency matrix, storing the set of immediate successors of each vertex together.
      • There is an $n+1$-dimensional vector $\vec A$ and an $m$-dimensional vector $\vec B$.
      • $d^+(v_i)=A(i+1)-A(i)$.
      • Any value from $B(A(i))$ to $B(A(i+1)-1)$ is an immediate successor of $v_i$.
    • An optional vector $\vec Z$ stores edge weights.
    • It can represent loops.
    • It can represent multiple edges.
  6. Backward star
    • Similar to the forward star, it stores the set of immediate predecessors of each vertex in a table.
  7. Adjacency list
    • Each entry in the list is of the form $|a|b|c|$: $a$ stores the vertex index, $b$ stores the edge weight, and $c$ stores the address pointer to the next list entry.
    • It can store edge weights.
    • It can represent loops.
    • It can represent multiple edges.

Chapter 2: Paths and Cycles

2.1 Connectivity of Graphs

  1. In directed graphs:

    Directed path, directed cycle: As the name implies.

    No repeated edges: Simple directed path/simple directed cycle.

    No repeated edges and no repeated vertices: Elementary directed path/elementary directed cycle, abbreviated as path and cycle.

  2. In undirected graphs:

    Path/chain, cycle: As the name implies.

    No repeated edges: Simple path/simple cycle.

    No repeated edges and no repeated vertices: Elementary path/elementary cycle.

Chord: An edge connecting two non-adjacent vertices on a cycle.

Connected graph: For any two vertices in $G$, there exists a path between them. $H$ is not a proper subgraph of any connected subgraph of $G$.

Tree: A connected graph with no cycles.

Cut edge/cut vertex: An edge/vertex whose removal makes the original graph disconnected.

Block: A maximal connected subgraph of $G$ with no cut vertices.

Equivalent propositions related to cut vertices:

  1. $v$ is a cut vertex of $G$.
  2. There exist vertices $u$ and $w$ different from $v$ such that any path $P_{uw}$ from $u$ to $w$ passes through $v$.
  3. $V\setminus{v}$ can be partitioned into two vertex sets $U$ and $W$; for any $u\in U$ and $w\in W$, $u$ lies on every path $P_{uw}$.

Equivalent propositions related to cut edges:

  1. $e$ is a cut edge of $G$.
  2. $e$ does not belong to any cycle in $G$.
  3. There exist vertices $u$ and $w$ in $G$ such that $e$ belongs to every path $P_{uw}$ between $u$ and $w$.
  4. $G\setminus{e}$ can be partitioned into two vertex sets $U$ and $W$ such that for any $u\in U$ and $w\in W$, every path $P_{uw}$ in $G$ passes through $e$.

If removing several vertices from graph $G$ results in two connected subgraphs or a single isolated vertex, the set of these vertices is called a vertex cut/separating set $A$.

$\mathcal K(G)=\min\limits_{A\in\emptyset}{|A|}$ is called the vertex connectivity.

Similarly, for an edge cut set $B$, the edge connectivity is $\lambda(G)$.

If $\mathcal K(G)\geq k$, $G$ is called a $k$-connected graph; similarly, a $k$-edge-connected graph.

$\mathcal K(G)\leq \lambda(G)\leq \delta(G)$, where $\delta(G)$ is the minimum degree of the vertices.

2.3 Eulerian Paths and Cycles

Eulerian cycle/path: A simple cycle/path that traverses all edges.

Eulerian graph: A graph that contains an Eulerian cycle.

Semi-Eulerian graph: A graph that contains an Eulerian path but no Eulerian cycle.

$An Eulerian cycle exists \Leftrightarrow$ the degree of every vertex is even / the out-degree equals the in-degree for every vertex.

$An Eulerian path exists \Leftrightarrow$ there are exactly two vertices with odd degree.

2.4 Hamiltonian Paths and Cycles

Hamiltonian cycle/path: An elementary cycle in an undirected graph that visits all vertices.

Hamiltonian graph: A connected undirected graph that contains a Hamiltonian cycle.

Semi-Hamiltonian graph: A connected undirected graph that contains a Hamiltonian path but no Hamiltonian cycle.

Some sufficient theorems:

  1. If $\forall v_i,v_j$, we always have $d(v_i)+d(v_j)\geq n-1$, then $G$ contains a Hamiltonian path.

  2. If $\forall v_i,v_j$, we always have $d(v_i)+d(v_j)\geq n$, then $G$ contains a Hamiltonian cycle.

  3. If every vertex in a simple graph has degree $\geq \cfrac n2$, then $G$ has a Hamiltonian cycle.

  4. Let $G$ be a simple graph, and $v_i, v_j$ be non-adjacent vertices satisfying $d(v_i)+d(v_j)\geq n$. Then $G$ has a Hamiltonian cycle if and only if $G+(v_i,v_j)$ has a Hamiltonian cycle.

  5. First, define a closed graph: If $d(v_i)+d(v_j)\geq n$, let $G’=G+(v_i,v_j)$, and repeat this process until no such vertex pair exists; the resulting graph is the closed graph, denoted as $C(G)$.

    A simple graph $G$ has a Hamiltonian cycle if and only if its closed graph $C(G)$ has a Hamiltonian cycle.

  6. If $C(G)$ is a complete graph, then $G$ has a Hamiltonian cycle.

2.6 Shortest Path: Dijkstra’s Algorithm

2.7 Critical Path: AOE

2.8 Chinese Postman Problem

First, identify the odd-degree vertices, select the shortest few paths to make these odd-degree vertices become even-degree vertices, and then construct an Eulerian cycle.

Chapter 3: Trees

3.1 Definitions Related to Trees

A connected graph with no cycles is called a tree ($T$). The edges in $T$ are called branches, and vertices with degree 1 are called leaves.

If $T$ is a spanning subgraph of $G$ and is also a tree, then $T$ is called a spanning tree/generator tree of $G$, or simply a tree of $G$.

3.5 Huffman Tree

The smaller value is placed on the left, the larger value on the right; 0 is on the left, 1 on the right.

3.6 Minimum Spanning Tree

  1. Kruskal’s algorithm: Continuously add the shortest edges; if a cycle forms, replace it with the next-shortest edge.
  2. Prim’s algorithm: Select the vertex closest to the already selected region.

Chapter 4: Planar Graphs and Graph Coloring

4.1 Planar Graphs

Planar graph: A graph that can be drawn on a plane without any intersecting edges. Such a drawing is called an embedding in the plane, and $G$ is a planar graph. One such embedding is called a planar representation of $G$.

If $G$ is isomorphic to a planar graph $P$, then $P$ is called a planar embedding of $G$.

Face/region: A region that contains no vertices or edges; the edges bounding the region are called its boundary.

Euler’s formula: For a connected planar graph, $d=m-n+2$.

If $G$ has $k$ connected components, then $n-m+d = k+1$.

For any general planar graph $G$, we always have $n-m+d\geq 2$.

If a connected planar graph $G$ has no cut edges and the boundary of each face has at least $t$ edges, then $m\leq\cfrac{t(n-2)}{t-2}$.

4.2 Maximal Planar Graphs

Maximal planar graph:

  1. Connected.
  2. Has no cut edges.
  3. The boundary of each face has 3 edges.
  4. $3d=2m$, $m=3n-6$, $d=2n-4$.

For a simple planar graph, $m\leq 3n-6$ and $d\leq 2n-4$.

There exist vertices with degree less than 6 in any simple planar graph $G$.

4.3 Non-planar Graphs

  1. $K_5$ is a non-planar graph, also called $K^{(1)}$.
  2. $K_{3,3}$ is a non-planar graph, also called $K^{(2)}$.
  3. Graphs obtained by adding some vertices of degree 2 to $K^{(1)}$ and $K^{(2)}$ are called $K^{(1)}$-type graphs and $K^{(2)}$-type graphs, collectively referred to as $K$-type graphs.
  4. A necessary and sufficient condition for $G$ to be planar is that $G$ contains no $K$-type subgraph.

4.4 Dual Graph

  1. Face $\rightarrow$ vertex, adjacent edges $\rightarrow$ adjacency; the process of finding the dual is called the D process (draw).
  2. Properties:
    1. If $G$ is a planar graph, then $G$ has a unique dual graph $G^*$.
    2. $G^*$ is a connected graph.
    3. If $G$ is a connected planar graph, then $(G^)^ = G$.
    4. $m=m^$, $n=d^$, $d=n^*$.
    5. If $C$ is an elementary cycle in a planar graph $G$, and $S^$ is the set of edges $e_i^$ in $G^$ corresponding to each edge $e_i$ on $C$, then $S^$ is a cut set of $G^*$.
    6. $G$ has a dual graph if and only if $G$ is planar.
  3. Every planar graph is 5-colorable.
  4. If a planar graph $G$ has a Hamiltonian cycle, then the four-color theorem holds.
  5. If the faces of any 3-regular planar graph are 4-colorable, then the faces of any planar graph are 4-colorable.
